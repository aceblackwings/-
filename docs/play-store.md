# 구글 플레이 출시 안내 (v0.74, 2026-11-13 결정: 1차는 구글 플레이만 · A안 = 앱에서는 유료 부적·등불 숨김)

## 0. 결정 사항
- 앱 = 지금 웹(`saju-app`)을 Capacitor로 감싼 안드로이드 앱(`app/`). 기록은 폰 안에만 저장(로그인 없음).
- **앱에서는 결제가 없음**: 소원 부적·100일 등불·토스 결제·상품 안내·환불 규정 링크를 숨김(`site.js inApp()` → `html.in-app`, `[data-web-only]`). 무료 기능(운세·타로·궁합·지신·걱정 태우기)은 모두 그대로. 앱 안에서 「웹에서 사세요」 같은 안내도 넣지 않음(구글 결제 정책).
- 애플(iOS)은 나중에 시도.
- 앱 아이디(패키지 이름) = `com.ockstar.zodiac12` (**한 번 올리면 바꿀 수 없음**).

## 1. 앱 파일 만들기 (자동)
- GitHub 저장소 → **Actions → 「안드로이드 앱 빌드」**: `claude/…`·`codex/…` 브랜치에 웹·앱 파일이 바뀌어 올라가면 자동 실행, 손으로도 실행 가능(Run workflow).
- 끝나면 실행 화면 맨 아래 **Artifacts**:
  - `zodiac12-release-aab` → 구글 플레이 콘솔에 올리는 파일
  - `zodiac12-debug-apk` → 내 폰에 바로 깔아 보는 시험용(설치 시 「출처를 알 수 없는 앱」 허용 필요)
- 서명 키(업로드 키): 저장소에 넣지 않음. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 두 개:
  - `ANDROID_KEYSTORE_BASE64` = 업로드 키 파일을 base64 글자로 바꾼 것
  - `ANDROID_KEYSTORE_PASSWORD` = 키 비밀번호 (별칭은 `upload`)
- 업로드 키 파일(`upload.jks`)·비밀번호는 **컴퓨터와 다른 곳(예: 비밀번호 관리 앱) 두 군데에 보관**. 잃어버리면 구글 플레이 고객 지원에 업로드 키 재설정을 요청해야 함(Play 앱 서명 사용 시 가능).
- 앱 아이콘·시작 화면·스토어 그림 다시 만들기: `python3 -I app/tools/make_icons.py` → `docs/store/icon-512.png`·`feature-1024x500.png`.

## 2. 구글 플레이 콘솔 순서
1. 개발자 계정(개인, 25달러) 가입 → 신분 확인·연락처 인증.
2. **앱 만들기**: 앱 이름 아래 「앱 이름」, 기본 언어 한국어, 앱(게임 아님), 무료.
3. **앱 설정(대시보드 할 일 목록)** — 아래 3절 답을 그대로.
4. **테스트 → 비공개 테스트** 트랙 만들기 → 테스터(이메일 목록 또는 구글 그룹) 등록 → AAB 업로드 → 검토 제출.
5. 테스터 **12명 이상이 「테스터 되기」를 누르고 앱을 설치해 14일 동안 계속** 참여.
6. 14일 뒤 대시보드에서 **프로덕션 액세스 신청**(테스트 소감 질문에 답) → 승인되면 프로덕션 출시 → 심사(며칠).

일정(목표 2026-12-22 출시): ~11/16 계정 가입·테스터 모집 → ~11/26 비공개 테스트 올리기 → **11/27까지 14일 테스트 시작** → 12/11 프로덕션 신청.
