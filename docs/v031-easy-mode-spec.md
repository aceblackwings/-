## 2. 할 일

### 2-1. 새 모듈 `js/easymode.js` (순수 로직, 테스트 `tests/easymode.test.mjs`)
- 저장 `unmyeong2099.easy` = `{ on: boolean, since: dateKey, by: 'self' | 'link', dismissed: boolean }`
- `emptyEasy()`, `setEasy(store, on, dateKey, by)`, `suggestEasy(birthYear, todayYear, store)` → 만 50세 이상 또는 만 16세 이하이고 아직 끄거나 닫지 않았으면 `true`
- `EASY_TERMS`: 사주 용어 → 쉬운 말 사전(쉬운 모드에서만 적용, 원래 용어는 괄호로 남겨 학습 가능하게)
  - 용신 → 나에게 필요한 기운(용신) · 희신 → 두 번째로 반가운 기운 · 기신 → 조심할 기운
  - 대운 → 10년 큰 흐름 · 세운 → 올해 흐름 · 월운 → 이달 흐름 · 일진 → 오늘 기운
  - 신강/신약/중화 → 기운이 센 편/여린 편/고른 편 · 조후 → 계절 균형
  - 십신 10개 → 한 줄 뜻(예: 정재 → 차곡차곡 모으는 기운, 편관 → 버텨 내는 기운)
- `easyTerms(text)`: `firstweek.plainTerms`(EXP→성장 점수, Lv.→성장) + `EASY_TERMS` 치환. **같은 단어를 두 번 바꾸지 않게**(이미 바뀐 문장은 그대로) 테스트할 것
- 테스트: 사전 치환, 이중 치환 없음, 금지어 없음(`habit.js toneProblems`), 추천 나이 경계(49/50세, 16/17세)

### 2-2. 켜고 끄는 곳 (3곳)
1. **가입 1단계**(`index.html` step 1): 체크 상자 「글씨를 크게, 말을 쉽게 볼래요」
2. **머리줄 버튼**: `#btn-edit`(정보 수정) 옆에 `가+` 버튼(켜짐이면 `가−`). 한 번 누르면 바로 바뀜
3. **추천 카드**: `suggestEasy`가 참이면 홈 맨 위에 한 번만 「글씨를 크게 볼까요? [크게 보기] [괜찮아요]」

### 2-3. 화면 크기와 대비 (`styles.css`)
- `html.easy { font-size: 125%; }` + px로 고정된 주요 글자(`.tl-lead`, `.dm-item`, `.umb-opt`, 탭 글자)는 `rem`으로 바꾸거나 `.easy` 덮어쓰기
- 버튼 최소 높이 48px, 누르는 칸 사이 8px 이상, `--muted` 글자색을 한 단계 밝게(대비 4.5:1 이상)
- 360px 폭에서 **가로 스크롤이 생기지 않을 것**(Playwright로 `document.documentElement.scrollWidth <= 360` 확인)

### 2-4. 쉬운 홈 = 카드 3장 (`app.js renderToday`)
쉬운 모드에서는 `timelineHTML()`·구역 목록 대신 아래 3장만 그린다.
1. **오늘**: 마음 날씨(`moodRowHTML`) → 큰 점수 + 「아주 좋은 하루예요」 한 줄 → 오늘의 우산(`umbrellaHTML`, 난이도 기본 🌱 30초)
2. **오늘의 미션 3가지**(`missionCardHTML`) — 그대로
3. **더 보기**: 「이번 주 · 이달 · 올해 보기」 버튼 하나 → 누르면 기존 타임라인 홈(쉬운 말·큰 글씨는 유지)
- 쉬운 모드에서는 「모든 기능 한 번에 펼치기」 버튼과 내년 카드 접힘 안내를 숨긴다

### 2-5. 쉬운 말 상시 적용 (`app.js setupPlainTerms`)
- 켜는 조건을 `첫 주 || 쉬운 모드`로 넓히고, 쉬운 모드면 `easyTerms`를 쓴다(MutationObserver 그대로 재사용)

### 2-6. 짝꿍이 대신 설정 — 서버 없이 링크로 (5-5절)
- 내 수호신 > 설정에 「부모님·아이 폰에 쉬운 모드 켜 주기」 → 링크 만들기: `?easy=1&remind=08:00&level=1`
- 링크로 연 사람에게 확인창 「○○님이 쉬운 모드를 추천했어요. 켤까요?」 → 수락하면 `setEasy(..., 'link')`. **거절하면 아무것도 바꾸지 않음**
- 링크에는 생년월일·이름을 넣지 않는다(설계 원칙 5)
- `remind`(알림 시각)는 정식 앱의 로컬 알림용으로 저장만 해 둔다(웹 미리보기는 알림 없음)
