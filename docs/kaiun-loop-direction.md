# 운명공방 2099 핵심 방향: 개운(開運) 성장 루프

> 작성일: 2026-11-01 · 상태: v0.11 프로토타입에 1차 구현

---

## 1. 한 문장 콘셉트

> **"매일 오늘의 운세를 보고 부적을 모으면, 부족한 오행이 차오르고, 내 수호 캐릭터가 신수로 진화할 때 올해 운이 최고점에 오른다. 그리고 앞으로 5년의 흐름도 해마다 더 좋아진다."**

---

## 2. 하루 루프 → 1년 루프 → 5년 루프

```
[하루]  운세 확인 → 오늘의 수집 (부적·스티커·이모티콘) → 액땜 미션 → 친구에게 스티커
            │                    │
            ▼                    ▼
[한 해]  오행 게이지 충전 → 개운 지수 상승 → 진화 조건 충족 → 신수 진화 = "올해 운 최상승"
                                    │
                                    ▼
[5년]   대운·세운(정통) 위에 "개운 반영 곡선"이 쌓임 → 해마다 개선 폭이 커지는 흐름
```

| 루프 | 사용자가 하는 일 | 사용자가 느끼는 것 | 구현 |
|---|---|---|---|
| 하루 | 운세 확인, 수집 3종 받기, 미션, 스티커 보내기 | "오늘도 챙겼다" | ✅ 오늘의 수집 카드 |
| 한 해 | 부적이 쌓여 오행 게이지가 차오름 | "막힌 기운이 뚫리고 있다" | ✅ 오행 충전 · 개운 지수 · 진화 조건 |
| 신수 | 개운 지수 75 + Lv.35 → 신수 진화 | "올해 운이 최고점에 오른다" | ✅ 신수의 가호 보너스 |
| 5년 | 대운·세운 화면에서 곡선 확인 | "내 앞으로 5년이 좋아지고 있다" | ✅ 5년 그래프와 표 |

## 3. 매일 수집 (오늘의 수집)

| 항목 | 내용 | 쓰임 |
|---|---|---|
| **오늘의 부적** | 고민에 맞는 종류, 용신 또는 가장 부족한 오행, 하루 고정 등급 | 도감 저장 + **오행 충전** (일반 3 / 희귀 5 / 영웅 8 / 전설 12 / 신화 20, 용신 ×1.5, 부족 ×1.3) |
| **오늘의 스티커** | 18종 (굿모닝·화이팅·합격 기원·부자 되세요·신수 강림 …), 등급별 확률 | **친구에게 보내는 대화용** 스티커 |
| **오늘의 이모티콘** | 수호 캐릭터 표정 8종 중 하나 | 이모티콘 도감, 캐릭터 장착(모은 것만) |

- 하루 한 번 "모두 받기" → 즉시 "火 화 기운 +8 충전! 개운 지수 0 → 8" 피드백
- 액땜 미션 완료 시 용신 +4(×1.5), 연속 출석·도감·인연 보상 부적도 충전

## 4. 오행 충전과 개운 지수

- 오행별 **목표치**: 부족한 기운일수록 목표가 높음 (16~34)
- **개운 지수(0~100)**: 다섯 게이지의 채움 정도를 평균. 용신 2배, 가장 부족한 기운 1.5배 가중
- **단계 해설**: 시작 → 발아(20) → 순풍(45) → 상승(75) → 대길(90)
- 해가 바뀌면 작년 기운의 30%를 이월 (새해에 다시 모을 이유 + 노력이 사라지지 않는 느낌)

### 진화 조건 = 레벨 + 개운 지수
| 단계 | 레벨 | 개운 지수 |
|---|---|---|
| 견습 수호령 | 5 | - |
| 수호 무사·선녀 | 10 | 20 |
| 수호신 | 20 | 45 |
| **신수** | **35** | **75** |

레벨만 높아서는 진화할 수 없고, **매일 오행을 채워야** 신수가 됩니다. 화면에는 "레벨은 충분해요! 개운 지수 75가 필요합니다(지금 52)"처럼 안내합니다.

## 5. 정통 사주 위의 개운 곡선

### 정통 계산 (그대로 보여 줌)
- **대운**: 양남음녀 순행·음남양녀 역행, 태어난 날부터 다음(이전) 절기까지 날수 ÷ 3 = 시작 나이, 월주에서 10년마다 한 칸씩
  - 검증: 1990년 6월 15일 남자 → 소서까지 22일 → 7세 癸未 대운 시작 (테스트로 확인)
- **세운**: 해마다의 간지 (2026 丙午, 2027 丁未 …)
- **점수**: 용신·기신 오행, 일지와의 합·충으로 계산한 기본 흐름

### 개운 반영 (게임 요소, 투명하게 구분)
- 개운 반영 = 기본 + 개운 지수 보너스(최대 +14) × **해마다 22%씩 커지는 누적 계수** + 진화 보너스(수호 무사 +2, 수호신 +4, 신수 +8)
- 그래프: 회색 점선(정통 기본) · **금색 실선(개운 반영)** · 분홍 점선(신수 진화·개운 100 목표선)
- 표: 해마다 세운 간지, 십신 테마, 기본 → 개운 반영 ▲개선 폭
- 요약: "지금처럼 꾸준히 개운하면 5년 동안 평균 ▲17, 2030년에는 ▲21까지 개선 폭이 커집니다"
- 대운 해설도 개운 지수에 따라 한 문장씩 밝아짐 ("개운이 충분히 쌓여 이 대운의 장점이 크게 살아납니다")

## 6. 왜 이렇게 설계했나 (심리 근거)

| 장치 | 원리 |
|---|---|
| 게이지가 눈에 보이게 차오름 | 목표 근접 효과: 목표가 가까울수록 더 열심히 한다 |
| 진화에 레벨 + 개운 둘 다 필요 | "매일 챙기는 행동"과 "결과(진화)"를 직접 연결 |
| 신수 = 올해 운 최상승 | 명확하고 감정적인 최종 목표 (기대감) |
| 5년 곡선의 개선 폭이 해마다 커짐 | 꾸준함이 복리처럼 쌓인다는 메시지 → 장기 유지 |
| 기본 흐름은 정통 그대로 공개 | 신뢰: 숫자를 부풀리지 않고 "내 노력분"을 따로 보여 줌 |
| 작년 기운 30% 이월 | 새해에 처음부터가 아님 → 이탈 방지 |

## 7. 신뢰와 책임 원칙

- **정통 기본 흐름과 개운 반영을 항상 나란히 표시**하고, 개운 반영은 "꾸준한 실천을 응원하는 게임 요소"라고 안내합니다.
- 결제로 개운 지수를 직접 올리는 상품은 만들지 않습니다. 유료 상품은 꾸미기·리포트·선물 위주로 둡니다. "돈 내면 운이 좋아진다"는 인상은 신뢰와 법적 리스크 모두에 위험하기 때문입니다.
- 화면 하단에 "운세와 부적의 효과 수치는 재미를 위한 게임 요소입니다"를 유지합니다.
