## 1. 이번에 반영한 것

| 요청 | 구현 |
|---|---|
| 초보자도 쉬운 시작 | 입력을 **3단계**로 나눔: ① 생일 → ② 고민·성별 → ③ 태어난 시간(몰라도 바로 소환). 고급 설정은 3단계 안에 접어 둠 |
| "고민을 돕고 있다"는 느낌 | **수호신 소환 화면**에서 "OO의 취업 고민, 30일 동안 매일 한 걸음씩 같이 풀어 가자!" + 3장 계획표 → 홈에 **고민 해결 여정 카드** (매일 작은 행동 1개 + 용신 오행에 맞춘 이유) |
| 단순한 홈 | 시작 화면을 **🏠 오늘**로. **오늘 할 일 3가지**(뽑기 · 여정 한 걸음 · 친구에게 스티커) 체크리스트. 탭 순서: 오늘 · 캐릭터 · 친구 · 풍수 지도 · 올해 리포트 · (그 외 기능) |
| 위치 기반 풍수 | **🗺️ 풍수 지도 탭**: 오늘의 행운 방향 × 용신 오행 장소 유형(숲·카페·전망대·맛집·산·한식당·종탑·베이커리·호수·찻집 등)으로 기운 스팟 3곳 추천 → 도착하면 **보물 상자**(멀수록 좋은 등급) + 오행 충전 1.5배 |
| 제휴 수익 기반 | **제휴 기운 스팟** 영역 (예시 매장, 방문 인증 쿠폰 구조) |
| 오방 신수 차별화 | 성장 단계(1~5)는 **레벨**로, 오방 신수·상위 신(6~14)은 **시련**으로: 연속 출석·친구 수·스티커·풍수 스팟·여정 완주·도감 칸 |
| 꾸준함과 친구 = 지름길 | **성장 가속**: 연속 출석 하루 +2%(최대 30%), 친구 1명 +5%(최대 30%) → 모든 퀘스트 경험치에 적용. 스티커 보내기 퀘스트와 "인연의 기운" 충전 |

## 2. 풍수 지도 · 제휴 수익 모델

### 구조
```
오늘의 운세(행운 방향) + 내 용신 오행 → 장소 유형 추천 → 길찾기(카카오맵 링크) → 150m 안 도착 → 보물 상자
```

### 수익화 단계
| 단계 | 모델 | 참고 사례 |
|---|---|---|
| 1 | **방문당 과금(CPV)**: 제휴 매장이 "기운 스팟"으로 노출되고, 인증 방문 1건당 비용 지급 | 포켓몬 GO 스폰서 위치: 방문 1건당 최대 약 0.5달러, 맥도날드 재팬·스타벅스 등 참여 (2017 공개 자료) |
| 2 | **제휴 한정 부적·쿠폰**: 매장 방문 시 "청룡 카페 한정 木 부적" + 할인 쿠폰 | 앱 아이템은 만드는 비용이 거의 없고, 매장은 손님이 늘어남 |
| 3 | **지자체·관광 연계**: 산·호수·사찰·전통시장 "기운 순례길" 스탬프 투어 | 지역 관광 활성화 예산과 연결 |
| 4 | **풍수 시즌 이벤트**: 입춘·동지에 특정 오행 스팟 보물 2배 | 시즌 집객 |

### 정식 버전에 필요한 것
- 장소 데이터: 카카오·네이버 지도 장소 검색 API(키 필요, 서버에서 호출) 또는 제휴 매장 DB
- 위치 위조 방지: 반복 위치 검사, 이동 속도 검사
- 위치정보법: 위치정보사업자·위치기반서비스사업자 신고 여부 검토. 위치는 기기에서 계산하고 저장하지 않는 현재 구조를 유지하는 것이 유리함
- 안전 안내: 운전 중 사용 금지, 야간 산행 주의, 사유지 출입 금지

## 3. 해외 진출 판단

### 시장 근거
- 점성술 앱 시장은 조사 기관마다 차이가 크지만 수억~수십억 달러 규모로 추정되고, 미국 MZ세대의 관심이 높다는 조사가 많습니다(업계 보고서, 참고용).
- **K-콘텐츠와 함께 사주에 대한 해외 관심이 늘고 있습니다.** K-드라마의 사주 장면, 서울의 사주 카페를 찾는 외국인 관광객, 대만 등 해외 유료 상담 사례가 보도되었습니다.
- 다만 **사주 용어가 어렵고**, 해외에서는 중국 바쯔(八字)나 무속과 혼동되는 문제가 있습니다.

### 판단: **국내 먼저 → 6~12개월 뒤 단계적 해외 확장** (동시 발매는 비추천)

| 선택지 | 장점 | 위험 | 판단 |
|---|---|---|---|
| 국내 집중 | 사주 친숙도 높음, 단톡방 바이럴, 제휴 매장 확보 쉬움 | 경쟁 앱 많음 | **1단계로 추천** |
| 동시 발매 | 규모 | 번역·문화 설명·결제·운영 비용 2~3배, 제품이 다듬어지기 전 해외 평점 하락 위험 | 비추천 |
| 국내 → 확장 | 국내에서 검증된 루프(여정·뽑기·궁합)를 그대로 가져감 | 시간 | **추천** |

### 확장 순서 제안
1. **대만·홍콩·싱가포르·일본**: 12지신과 띠 문화가 이미 익숙함 → 튜토리얼 부담 적음
2. **동남아(태국·베트남·필리핀)**: K-콘텐츠 인기와 띠·운세 문화
3. **미국·유럽**: "K-Saju"로 브랜딩. 별자리에 익숙한 MZ세대에게 **"내 별자리 대신 내 수호 동물"**로 설명

### 해외 튜토리얼 설계 (가능성 높음)
- 3장면 튜토리얼: ① "당신이 태어난 해의 동물이 수호신이 됩니다" (12지신 경주 이야기 30초 애니메이션) ② "다섯 가지 기운(나무·불·흙·쇠·물)의 균형" (별자리 4원소에 비유) ③ "매일 부적을 모아 부족한 기운을 채우세요"
- 용어는 영어로 풀어 씀: 용신 → "Your lucky element", 대운 → "10-year luck cycle", 부적 → "Talisman (Bujeok)"
- 문화 존중: 실제 무속·종교 의식처럼 보이지 않게 **"전통 상징을 재해석한 게임"**으로 안내
- 기술: 지금 코드에서 문구를 언어 파일로 분리하면 다국어 전환 가능. 사주 계산은 출생지 시간대(현재는 한국 표준시 기준)를 국가별로 받아야 함 → 해외 버전의 필수 작업

## 5. "사주 소셜 최고"를 위한 추가 아이디어

### 꼭 추천하는 5가지
1. **🗣️ AI 수호신 대화**: 내 띠 캐릭터가 띠 말투로 고민 상담. 무료 하루 3회, 구독 무제한. 가장 강력한 리텐션·수익 기능
2. **👥 단톡 궁합방**: 링크 하나로 단톡방 전원 궁합 지도·오늘의 행운 멤버 → 가장 빠른 바이럴 고리
3. **🎁 부적 선물하기**: 친구 고민에 맞는 부적을 선물(무료 1장/일, 유료 맞춤). 카카오 선물하기 습관과 연결
4. **📸 신수 진화 공유 카드**: "2026년 운 최고점 도달!" 배지 카드. 진화 순간 자동 생성
5. **🏮 계절 축제 이벤트**: 설날(띠 교체)·입춘·칠석·추석·동지 한정 부적·스킨·풍수 스팟

### 지금 설계의 세부 개선 추천
| 영역 | 개선 |
|---|---|
| 홈 | 상단 점수 카드와 캐릭터 말풍선을 합쳐 "캐릭터가 오늘 운세를 말해 주는" 한 장으로 → 화면 길이 절반 |
| 여정 | 걸음 완료 시 캐릭터가 고민 키워드로 칭찬 ("면접 준비 한 걸음! 이 몸이 자랑스럽다, 어흥!") |
| 뽑기 | 7일 연속 출석 시 무료 뽑기 1회 추가 (꾸준함 보상) |
| 친구 | 친구가 내 캐릭터를 응원하면 내 오행이 +2 충전 (친구 = 지름길 강화) |
| 풍수 | 스팟 방문 사진 인증 → 스토리 카드 자동 생성 |
| 리포트 | 월초에 "이번 달 개운 전략" 푸시 알림 1회 |
| 신뢰 | 정통 계산 근거를 "왜 이 점수?" 버튼으로 펼쳐 보기 |
| 접근성 | 글씨 크게 보기, 고대비 모드 (중장년층 확장 대비) |
