# 최종 방향 결정: 엄마와 딸이 함께 "운을 습관으로 바꾸는" 앱

> 작성일: 2026-11-03 · 대상 버전: v0.30 ~ 정식 앱 전환 · 이전 방향 문서: `kaiun-loop-direction.md`(개운 성장 루프), `social-design.md`(친구·소모임), `core-saju-review-plan.md`(경쟁 앱 리뷰)
> 이 문서는 (1) 사주 엔진 고도화 질문 3가지에 대한 답, (2) 사주 만족도를 올리는 원칙, (3) 엄마·딸 습관 앱으로 가기 위한 **결정 10가지와 설계**를 담는다.

---

## 0. 한 문장 결정

> **"사주는 오늘의 날씨, 미션은 우산. 엄마와 딸이 서로의 날씨를 보고 우산을 챙겨 주며, 어제보다 나은 오늘의 나를 함께 쌓아 가는 앱."**

- 운세는 **입구**(왜 들어오는가), 행동 미션은 **본체**(매일 무엇을 하는가), 엄마·딸 관계는 **지속 이유**(왜 계속 오는가)다.
- 북극성 지표: **주간 활성 쌍** = 엄마와 딸 둘 다 그 주에 미션을 3번 이상 완료한 쌍의 수.

## 1. 사주 엔진 질문 3가지에 대한 답

### Q1. 『궁통보감』 120조합 조후표를 넣으면 지금 간이 규칙과 얼마나 달라질까?

| 비교 | 지금(v0.29 간이 규칙) | 120조합 조후표 |
|---|---|---|
| 판단 단위 | 계절(월지)만 보고 **오행** 하나(물 또는 불) | 일간 10 × 월지 12 = 120칸마다 **천간 글자** 1~2개(예: 午월 庚금 → 壬수, 子월 丙화 → 壬수·戊토) |
| 적용 범위 | 8개 달에만 적용, 봄·가을 한가운데(卯·辰·申·酉)는 조후 없음 | 12개 달 전부. 봄·가을에도 "庚금을 다듬는 丁화" 같은 처방이 있음 |
| 결과의 구체성 | "물이 필요해요" | "큰 강물 같은 壬수가 필요해요(이슬 같은 癸수와 구분)" |

- **한여름·한겨울**은 두 방식이 대체로 같은 방향(여름 물, 겨울 불)이라 결과가 크게 바뀌지 않는다.
- **봄·가을 출생**은 지금 "조후 없음"인데 표를 넣으면 새 처방이 생긴다. 즉 차이는 주로 봄·가을 출생자에게서 생긴다. 지금 표본 기준 용신이 바뀐 비율은 14%이고, 표를 넣으면 추가로 바뀌는 사람이 상당수(대략 1~2할로 추정) 생길 것이다. **정확한 수치는 표를 넣은 뒤 같은 2,880명 표본으로 다시 재서 보고한다**(추정을 사실처럼 쓰지 않기 위해).
- 더 큰 가치는 숫자보다 **구체성**이다. 오행 단위("물")에서 천간 단위("壬수 = 큰 물, 癸수 = 단비")로 내려가면 풀이 문장이 개인에게 꼭 맞는 느낌을 준다. 사용자가 "맞다"고 느끼는 핵심이 바로 이 구체성이다.
- 비용: 데이터 약 5KB, 계산 시간 변화 없음.

### Q2. 조후 기준값(15%·25%)은 어떻게 검증하고 조정해야 믿을 만할까?

순서대로 4단계.

1. **정답 세트 만들기**: 명리 전문가 **2명 이상**이 서로 모르게 60~100개 명식의 용신·희신을 판정한다. 일간 10종 × 사계절이 고르게 섞이도록 고른다.
2. **상한선 확인**: 용신은 학파마다 다르므로 **전문가끼리의 일치율**이 곧 우리가 노릴 수 있는 최고치다(예: 둘이 75% 일치하면 엔진 목표도 75% 근처).
3. **기준값 찾기**: 정답 세트를 절반으로 나눠 앞 절반으로 기준값(10~30%, 5% 단위)과 우선순위 규칙을 맞추고, **뒤 절반으로만 성적을 잰다**(과적합 방지).
4. **실사용 신호로 보정**: 기록함의 「어제 운세 맞았나요?」 응답을 용신 판정 방식(억부·조후 우선·보완)별로 나눠 "맞았어요" 비율을 비교한다. 수천 건이 쌓이면 사용자 체감 정확도가 높은 쪽으로 미세 조정한다.

경쟁 앱 결과와의 비교는 **보조 지표**로만 쓴다(그쪽 계산법도 공개되지 않았고 앱끼리도 다르기 때문).

### Q3. 격국과 형·파·해 중 무엇을 먼저?

**격국을 먼저 넣는다.** 이유는 이 앱의 목표가 "불안을 덜고 노력할 마음을 심는 것"이기 때문이다.

| | 격국 | 형·파·해 |
|---|---|---|
| 알려 주는 것 | 타고난 그릇·일하는 방식·강점 (정관격 = 원칙과 신뢰의 사람) | 글자끼리 부딪쳐 생기는 마찰·변동 시기 |
| 사용자 감정 | "나는 이런 강점이 있구나" → **자기 이해·긍정** | "이때 조심해야 하는구나" → **경고·불안** |
| 만족도 효과 | 정통 풀이의 깊이가 확 올라감(경쟁 앱 유료 풀이의 핵심 항목) | 맞추는 재미는 있지만, 잘못 쓰면 불안을 키움 |
| 미션과의 연결 | 격국별 "강점 키우기 미션" | 시기별 "대비 미션"(경고를 행동으로 바꿈) |

형·파·해는 격국 다음에, **반드시 "대비 미션"과 짝을 지어** 넣는다(경고만 단독으로 보여 주지 않는다는 원칙, 3절 참조).

## 2. 사주 만족도를 올리는 5가지 축

사람들이 "이 앱 사주 잘 본다"고 느끼는 요소를 나눠 보면 다음 5가지다. 엔진 고도화는 이 축을 기준으로 우선순위를 정한다.

| 축 | 사용자가 느끼는 것 | 현재 상태 | 다음 할 일 |
|---|---|---|---|
| ① 맞는다 (구체성) | "나만의 이야기다" | 오행 단위라 일반론처럼 들릴 수 있음 | 120 조후표(천간 단위), 격국, 원국 글자를 문장에 직접 인용("태어난 달의 未토가…") |
| ② 이해된다 | "왜 그런지 알겠다" | ✅ 모든 점수에 근거 한 줄 | 용어를 쉬운 말로(엄마 모드에서 더 쉽게) |
| ③ 일관된다 | "볼 때마다 같다" | ✅ 엔진 하나, 무작위 없음 | 유지 |
| ④ 희망이 있다 | "노력하면 되겠다" | 일부(액땜 미션) | **모든 출력에 행동 1개**(3절 문법) |
| ⑤ 증명된다 | "실제로 맞았다" | ✅ 「어제 운세 맞았나요?」 | 개인 적중 통계를 월간 카드로("이번 달 내 운세 적중 72%") |

①과 ⑤가 경쟁 앱과의 차이를 만든다. ④는 이 앱의 정체성이다.

## 3. 핵심 문법: "날씨 → 우산" (모든 운세 출력의 규칙)

불안의 본질은 **불확실성**이다. 사주가 불안을 덜어 주는 순간은 "미래를 알았을 때"가 아니라 **"내가 할 수 있는 일이 보였을 때"**다. 그래서 모든 운세 출력은 다음 4칸을 반드시 채운다.

```
① 날씨(정직한 근거)  →  ② 해석(긍정 프레임)  →  ③ 우산(행동 1개, 5분 이내)  →  ④ 확인(했나요? → 보상)
   "오늘 재물 58점,       "돈이 새기 쉬운 날이니,     "오늘 결제 전 10초만         "참았어요 ✔ → 복주머니 +1,
    일진이 기신(土)"        지키는 쪽이 이기는 날"       장바구니 다시 보기"            엄마에게 자동 응원"
```

### 문장 규칙 (테스트로 검사)
1. **경고 단독 금지**: "조심" 문장이 있으면 같은 카드 안에 미션 버튼이 있어야 한다.
2. **금지어**: 나쁜 날·최악·불길·망·흉(단독) → "준비하는 날·쉬어 가는 날·지키는 날"로 바꿔 쓴다.
3. **노력 연결어**: 낮은 점수 문장에는 "~하면 흐름이 바뀌어요" 형태의 조건문을 하나 넣는다.
4. **정직 유지**: 점수를 부풀리지 않는다(설계 원칙 2). 바꾸는 것은 **해석과 행동**이지 숫자가 아니다.
5. **안전**: 의료·법률·투자 단정 금지, 위기 신호 시 109 안내(기존 유지).

### "마음 날씨" 체크인 (불안을 덜어 줬는지 재는 장치)
- 운세 보기 전: "지금 마음 날씨는?" ☀️🌤️☁️🌧️⛈️ (한 번 탭)
- 미션 완료 후: "조금 가벼워졌나요?" (예/그대로)
- 이 두 값으로 **"운세 + 미션이 마음을 가볍게 한 비율"**을 잰다. 앱의 존재 이유를 숫자로 확인하는 지표다.
- ⛈️가 3일 이상 이어지면 부드럽게 상담 자원(109·1577-0199)을 안내한다.

## 4. 결정 10가지

| # | 결정 | 근거 |
|---|---|---|
| D1 | **정체성** = 운세 앱이 아니라 "운을 습관으로 바꾸는 엄마·딸 앱" | 2030 운세 소비의 동기는 불안 해소이고([아시아경제](https://view.asiae.co.kr/article/2024021615163977330)), 점신 운영사도 MZ가 운세를 "자기계발 습관"처럼 쓴다고 설명([한경](https://magazine.hankyung.com/business/article/202410045035b)). 습관 앱 자리가 비어 있음 |
| D2 | **북극성 지표** = 주간 활성 쌍 | 혼자 쓰는 운세 앱은 광고 피로·흥미 저하로 이탈(점신 리뷰 44%가 광고 불만). 관계가 걸리면 이탈 비용이 커짐 |
| D3 | **날씨→우산 문법**을 모든 출력에 강제 | 3절. 불안 → 행동 전환이 핵심 가치 |
| D4 | **미션은 30초~5분, 앵커형, 자기 보고** | Fogg의 Tiny Habits(기존 일과 뒤에 아주 작은 행동 + 즉시 축하) 방식([개요](https://concepts.dsebastien.net/concept/tiny-habits/)), "언제·어디서·무엇을" 계획(실행 의도)은 목표 달성에 중간~큰 효과(d=0.65, Gollwitzer & Sheeran 2006, [요약](https://kops.uni-konstanz.de/entities/publication/2e749bfb-8533-437c-8203-7e788c910c5f)). 단, Fogg 방식의 독립 검증 연구는 아직 적어 "참고 원리"로만 씀 |
| D5 | **엄마 모드**(큰 글씨·쉬운 말·버튼 3개 홈) | 50~60대 엄마가 막히면 쌍이 깨짐. 딸이 대신 설치·설정해 줄 수 있게 |
| D6 | **자유 채팅 없음**, 정해진 응원·도장·질문 카드로만 소통 | 기존 소셜 설계 원칙 유지(안전·부담 감소). 엄마·딸 사이의 "말 꺼내기 어색함"을 카드가 대신해 줌 |
| D7 | **보상 3층**(감정·성장·관계), 돈으로 운을 사지 않음 | 5절. 기존 원칙 3 유지 |
| D8 | **연속 기록은 주 단위 + 쉬어 가기권** | 하루 끊기면 0이 되는 구조는 죄책감을 만듦. 듀오링고 스트릭 프리즈가 이탈 위험 사용자 이탈을 줄였다는 사례가 있으나 원 출처 미확인([사례](https://jiwonvyoo.github.io/portfolio/case/duolingo/duo.html)) → 우리는 "주 3회면 유지"로 더 관대하게 |
| D9 | **사주 고도화 순서** = 120 조후표 → 검증 세트 → 격국 → 문장 DB(전문가 감수) → 형·파·해(대비 미션 짝) | 1절·2절 |
| D10 | **웹 프로토타입으로 루프 검증 → 정식 앱(푸시 알림·서버)** | 습관 앱은 알림이 필수인데 웹 미리보기는 푸시가 안 됨. 쌍 기능도 서버 필요 |

## 5. 설계

### 5-1. 하루 루프 (엄마와 딸 각자 + 함께)

```
아침  ① 마음 날씨 탭 → ② 오늘의 날씨(운세 한 줄 + 근거) → ③ 오늘의 우산(미션 3개 중 1개 이상 선택)
낮    ④ 미션 완료 탭(사진은 선택) → 캐릭터 반응 + 복주머니 +1 → 상대에게 "했어요" 자동 알림
저녁  ⑤ 상대의 하루 한 줄 보기 → 응원 도장 꾹 → ⑥ 오늘의 대화 질문 1개(선택)
다음날 ⑦ 「어제 운세 맞았나요?」 → 적중 기록 → 다시 ①
```

홈 화면은 **카드 3장**으로 단순화한다: ① 오늘의 날씨와 우산(내 것) ② 엄마(딸)의 오늘(상대 것, 동의된 요약) ③ 함께 미션과 가족 복주머니.

### 5-2. 미션 설계

| 구분 | 내용 | 예시 |
|---|---|---|
| 출처 | 오늘 운세의 약한 분야 + 용신 오행 + 내 고민 | 수(水) 용신 → "점심 뒤 물 한 컵", 재물 낮음 → "결제 전 10초 멈춤" |
| 난이도 3단 | 🌱 30초 / 🌿 5분 / 🌳 30분 | 🌱 창문 열고 심호흡 3번 · 🌿 산책 · 🌳 방 한 칸 정리 |
| 앵커 | "~한 뒤에" 형식으로 제시 | "양치한 뒤에 거울 보고 칭찬 한마디" |
| 확인 | 한 번 탭(자기 보고). 사진·한 줄 메모는 선택 | 증명 강요는 부담 → 정직성은 관계(상대가 봄)로 확보 |
| 함께 미션 | 둘이 같은 미션, 둘 다 하면 보상 2배 | "서로에게 오늘 고마운 점 하나 보내기", "같은 노래 듣기" |
| 쉬움 기준 | **초등 고학년이 설명 없이 할 수 있는 수준** | 글을 읽지 않아도 아이콘으로 이해 |
| 라이브러리 | 6분야 × 5오행 × 3난이도 ≈ 90개로 시작, 계절·명절판 추가 | 계절 한정 패키지(season.js)와 연결 |

### 5-3. 보상 3층

| 층 | 무엇 | 느끼는 것 | 이미 있는 자산 |
|---|---|---|---|
| ① 즉시 감정 | 캐릭터가 기뻐하는 표정·대사, 쓰다듬기 반응 | "잘했다" (Fogg의 축하) | 12띠 × 표정 8종 그림 96장, 말투 가이드 |
| ② 누적 성장 | 경험치 → 진화 5단계(+승천), 부적·소품·장면 도감 | "나는 자라고 있다" | 진화 그림 60장, 부적·소품 시트 |
| ③ 관계 | 상대에게 주는 응원 도장, **가족 복주머니**(둘의 미션으로 함께 차오름, 가득 차면 가족 부적·장면 해금) | "우리가 함께 해냈다" | 우편함(db), 실시간 방(room) |

- 뽑기 재화는 **미션으로만** 얻는다(결제로 운을 올리지 않음). 확률 공개 유지.
- 현실 보상(기프티콘·제휴)은 정식 앱 단계에서, 운세 결과와 무관한 "꾸준함 보상"으로만 검토한다.

### 5-4. 엄마·딸 관계 기능 (우선순위 순)

1. **초대·연결**: 딸이 링크 하나로 엄마를 초대(엄마는 생일만 넣으면 끝). 연결은 서로 동의해야 성립.
2. **서로의 오늘 한 줄**: 상대의 띠·오늘 총운 구간(좋음/보통/준비)·완료한 미션만 보인다. **생년월일·사주 원본은 공유하지 않는다**(원칙 5 유지).
3. **함께 미션 + 응원 도장**: 5-2, 5-3.
4. **우리 둘 사용설명서**: 엄마·딸 궁합을 "누가 옳다"가 아니라 **대화 팁**으로 풀이("엄마는 火가 강해 먼저 말하고, 딸은 水가 강해 생각 후 말해요 → 엄마가 질문하고 10초 기다리기"). 기존 compat.js 확장.
5. **오늘의 대화 질문**: 사주와 연결된 질문 카드("엄마의 20대 대운은 식신운이었어요. 그때 가장 즐거웠던 일은?"). 답은 둘만 본다. 쑥스러운 말을 앱이 대신 꺼내 준다.
6. **가족 복주머니**: 5-3 ③.
7. (나중) 아빠·형제 초대로 가족 3~4인 확장.

### 5-5. 엄마 모드

- 글자 크게(기본 대비 1.25배), 버튼 크게, 한 화면에 카드 3장까지.
- 용어를 쉬운 말로(용신 → "나에게 필요한 기운", 대운 → "10년 큰 흐름"). 첫 7일의 쉬운 용어 기능(firstweek.js)을 엄마 모드에서는 상시 적용.
- 딸이 대신 설정: 엄마 기기의 알림 시간·미션 난이도를 딸이 추천할 수 있음(엄마가 수락).

### 5-6. 사주 고도화 로드맵 (2절 축과 연결)

| 단계 | 내용 | 올라가는 축 |
|---|---|---|
| E1 | 120 조후표(천간 단위) + 문장에 원국 글자 인용 | ① 구체성 |
| E2 | 정답 세트(전문가 2인 60~100명식)로 용신 검증·기준값 조정 | ① 정확성 |
| E3 | 격국 + 격국별 강점 풀이 + 강점 미션 | ①·④ |
| E4 | 풀이 문장 DB 확장(십신 × 12운성 × 기간), 전문가 감수 | ① |
| E5 | 형·파·해·원진(원국·대운·세운) + 대비 미션 짝 | ①·④ |
| E6 | 월간 적중 카드("이번 달 내 운세 적중 72%") | ⑤ 증명 |

## 8. 위험과 대응

| 위험 | 대응 |
|---|---|
| 운세 의존이 커짐 | 미션이 본체라는 구조 자체가 대응. "운세보다 내가 한 일" 통계를 더 크게 보여 줌 |
| 엄마·딸 사이 감시처럼 느껴짐 | 공유 항목은 요약만, 언제든 숨기기, "오늘은 혼자 할래요" 버튼 |
| 경쟁·비교로 관계가 상함 | 순위 없음, 둘이 함께 채우는 복주머니만 |
| 미성년자 | 14세 미만은 보호자 동의 절차(소셜 설계 5절), 결제 제한 |
| 개인정보 | 생년월일·사주 원본은 기기에만. 서버에는 동의된 요약(띠·점수 구간·미션 완료)만. 출시 전 개인정보 처리방침 전문가 검토 |
| 사주 해석 논쟁 | 판정 근거와 학파 차이를 전문가 보기에서 투명하게 공개 |
