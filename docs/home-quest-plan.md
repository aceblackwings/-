# 홈 화면 개편 기획: 2027년 운세 + 「다음 할 일」 길잡이 (v0.21)

작성 2026-11-02 · 대상 브랜치 `ccr-c85c770a-b6ueyf`

## 1. 문제
- 사주를 넣고 들어오면 홈이 한 줄로 길게 이어진다(390px 기준 약 4,000px). 운의 흐름 카드 6장 + 질문 메뉴 + 계절 패키지 + 축제 + 수호신 한마디 + 오늘 할 일 + 여정 + 뽑기 + 고민 카드 + 액땜 미션 + 스토리 공유까지 한 번에 보인다.
- 처음 쓰는 사람(특히 50~70대)은 "무엇부터 봐야 하는지"를 모른다. 펼치기(▾)가 있다는 것도 잘 알아채지 못한다.
- 11월~2월은 "내년 운세"를 찾는 사람이 가장 많은 시기인데, 홈에는 내년 운세가 없다.

## 2. 원칙
1. 첫 화면은 3장만: **2027년 운세(맨 위) → 오늘의 운세(펼친 상태) → 올해 운세**
2. 오늘의 운세가 처음부터 펼쳐져 있으면, 나머지 카드도 "눌러서 펼치는 것"임을 바로 알 수 있다.
3. 나머지 기능은 버리지 않고 **「다음 할 일」 퀘스트 카드 한 장**이 하나씩 열어 준다. 카드에는 진행도(n/9), 한 줄 설명, 버튼 1개만 둔다.
4. 익숙한 사람을 위한 탈출구: 「모든 기능 한 번에 펼치기」 / 「간단히 보기」 전환.
5. 숫자는 모두 기존 period.js 한 엔진에서 나온다(내년 = `yearOf(saju, 사주년+1)`). 정통 점수는 부풀리지 않는다.

## 3. 첫 화면 구성
| 순서 | 카드 | 처음 상태 | 내용 |
|---|---|---|---|
| 1 | 🎁 2027 丁未(정미)년 운세 | 접힘(요약은 보임, 강조 테두리) | 점수, 올해 대비 ±, 테마, 좋은 달 / 펼치면 12달 막대·상반기·하반기·좋은 달·조심할 달·근거·「2027년 운세 풀이 자세히」 |
| 2 | 🧭 다음 할 일 | 항상 | 진행도 + 지금 할 1가지 (v0.21.1: 오늘 카드가 길어 첫 화면 밖으로 밀려서 내년 카드 바로 아래로 올림) |
| 3 | ☀️ 오늘 | **펼침** | 기존과 같음 |
| 4 | 📅 올해 | 접힘 | 기존과 같음 |
| 5~ | 열린 기능 | - | 퀘스트로 연 순서대로 아래에 쌓임 |

- 내년 카드 표시 기간: **9월 1일 이후 또는 입춘 전**(입춘 전에는 "사주상 올해"가 아직 지난해이므로 내년 = 새해). 입춘 이후에는 "올해" 카드가 그 역할을 맡으므로 숨긴다.
- 운세 풀이(사주 탭)에도 「🎁 2027년」 탭을 추가한다. 문장은 "올해는" 대신 "2027년은"으로 시작한다.
- 첫 가입 직후 「사주 한 장 요약」에도 2027년 한 줄을 넣는다.

## 4. 퀘스트 순서 (열리는 것)
| # | 퀘스트 | 버튼을 누르면 | 여는 것 |
|---|---|---|---|
| 1 | 🎁 2027년 운세 펼쳐 보기 | 내년 카드 펼침 | (내년 카드는 이미 보임. 표시 기간이 아니면 건너뜀) |
| 2 | 🗓️ 이번 주 가장 좋은 날 찾기 | 이번 주 카드 열고 펼침 | 이번 주 |
| 3 | 🌙 이달 좋은 날·조심할 날 보기 | 이달 카드 열고 펼침 | 이달 |
| 4 | 🧧 오늘의 액땜 미션 받기 | 미션 카드로 이동 | 액땜 미션 |
| 5 | 🔮 운명 뽑기로 첫 부적 받기 | 뽑기 카드로 이동 | 오늘의 뽑기 |
| 6 | 💬 수호신에게 물어보기 | 질문 메뉴로 이동 | 무엇이 궁금하세요? |
| 7 | 🏔️ 나의 10년 대운 보기 | 대운 카드 열고 펼침 | 대운 · 타고난 나 |
| 8 | 🧭 고민 해결 여정 시작 | 여정 카드로 이동 | 고민 카드 · 30일 여정 |
| 9 | ✅ 매일 할 일 목록 열기 | 할 일 카드로 이동 | 오늘 할 일 · 수호신 한마디 · 계절 한정 · 축제 · 스토리 공유 |

- 퀘스트 1개 완료 = +3 EXP(수호신 성장에 반영, 운세 점수와는 무관).
- 1번은 사용자가 직접 내년 카드를 펼쳐도 완료된다.
- 다른 화면의 버튼(예: 타임라인의 「30일 해결 여정으로 풀기」)이 아직 잠긴 기능을 부르면 그 자리에서 열어 준다(막다른 길 없음).
- 9개를 다 끝내면 퀘스트 카드는 「길잡이 완료」 한 줄로 줄고, 홈은 지금과 같은 전체 구성이 된다.
- 저장: `localStorage['unmyeong2099.guide'] = { done: [키…], all: false }`. 판단 로직은 `js/guide.js`(순수 함수, 테스트 있음).

## 5. 기대 효과
- 첫 화면 높이: 약 4,000px → 약 1,700px(오늘 카드 펼침 기준)
- 첫 방문 행동이 "읽기 → 버튼 1개"로 고정되어, 다음 행동을 고민할 필요가 없음
- 11~2월 내년 운세 수요를 첫 화면에서 바로 받음 → 공유·재방문 계기
