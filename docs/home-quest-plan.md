# 홈 화면 개편 기획: 2027년 운세 + 「다음 할 일」 길잡이 (v0.21)

작성 2026-11-02 · 대상 브랜치 `ccr-c85c770a-b6ueyf`

## 1. 문제
- 사주를 넣고 들어오면 홈이 한 줄로 길게 이어진다(390px 기준 약 4,000px). 운의 흐름 카드 6장 + 질문 메뉴 + 계절 패키지 + 축제 + 수호신 한마디 + 오늘 할 일 + 여정 + 뽑기 + 고민 카드 + 액땜 미션 + 스토리 공유까지 한 번에 보인다.
- 처음 쓰는 사람(특히 50~70대)은 "무엇부터 봐야 하는지"를 모른다. 펼치기(▾)가 있다는 것도 잘 알아채지 못한다.
- 11월~2월은 "내년 운세"를 찾는 사람이 가장 많은 시기인데, 홈에는 내년 운세가 없다.

## 2. 원칙
1. 첫 화면은 3장만: **2027년 운세(맨 위) → 오늘의 운세(펼친 상태) → 올해 운세**
2. 오늘의 운세가 처음부터 펼쳐져 있으면, 나머지 카드도 "눌러서 펼치는 것"임을 바로 알 수 있다.
3. 나머지 기능은 버리지 않고 **「다음 할 일」 퀘스트 카드 한 장**이 하나씩 열어 준다. 카드에는 진행도(n/9), 한 줄 설명, 버튼 1개만 둔다.
4. 익숙한 사람을 위한 탈출구: 「모든 기능 한 번에 펼치기」 / 「간단히 보기」 전환.
5. 숫자는 모두 기존 period.js 한 엔진에서 나온다(내년 = `yearOf(saju, 사주년+1)`). 정통 점수는 부풀리지 않는다.

## 3. 첫 화면 구성
| 순서 | 카드 | 처음 상태 | 내용 |
|---|---|---|---|
| 1 | 🎁 2027 丁未(정미)년 운세 | 접힘(요약은 보임, 강조 테두리) | 점수, 올해 대비 ±, 테마, 좋은 달 / 펼치면 12달 막대·상반기·하반기·좋은 달·조심할 달·근거·「2027년 운세 풀이 자세히」 |
| 2 | 🧭 다음 할 일 | 항상 | 진행도 + 지금 할 1가지 (v0.21.1: 오늘 카드가 길어 첫 화면 밖으로 밀려서 내년 카드 바로 아래로 올림) |
| 3 | ☀️ 오늘 | **펼침** | 기존과 같음 |
| 4 | 📅 올해 | 접힘 | 기존과 같음 |
| 5~ | 열린 기능 | - | 퀘스트로 연 순서대로 아래에 쌓임 |

- 내년 카드 표시 기간: **9월 1일 이후 또는 입춘 전**(입춘 전에는 "사주상 올해"가 아직 지난해이므로 내년 = 새해). 입춘 이후에는 "올해" 카드가 그 역할을 맡으므로 숨긴다.
- 운세 풀이(사주 탭)에도 「🎁 2027년」 탭을 추가한다. 문장은 "올해는" 대신 "2027년은"으로 시작한다.
- 첫 가입 직후 「사주 한 장 요약」에도 2027년 한 줄을 넣는다.

| 2 | 🗓️ 이번 주 가장 좋은 날 찾기 | 이번 주 카드 열고 펼침 | 이번 주 |

| 8 | 🧭 고민 해결 여정 시작 | 여정 카드로 이동 | 고민 카드 · 30일 여정 |
| 9 | ✅ 매일 할 일 목록 열기 | 할 일 카드로 이동 | 오늘 할 일 · 수호신 한마디 · 계절 한정 · 축제 · 스토리 공유 |

- 퀘스트 1개 완료 = +3 EXP(수호신 성장에 반영, 운세 점수와는 무관).
- 1번은 사용자가 직접 내년 카드를 펼쳐도 완료된다.
- 다른 화면의 버튼(예: 타임라인의 「30일 해결 여정으로 풀기」)이 아직 잠긴 기능을 부르면 그 자리에서 열어 준다(막다른 길 없음).
- 9개를 다 끝내면 퀘스트 카드는 「길잡이 완료」 한 줄로 줄고, 홈은 지금과 같은 전체 구성이 된다.
- 저장: `localStorage['unmyeong2099.guide'] = { done: [키…], all: false }`. 판단 로직은 `js/guide.js`(순수 함수, 테스트 있음).

## 7. v0.27 개편 (2026-11-02 밤): 오늘 펼침 + 이달·올해 작은 창 + 오늘의 미션 3가지

**요청**: 2027년 운세 바로 아래 오늘 운세(펼침), 이달·올해는 작은 창, 「다음 할 일」을 이달 운세와 이어지는 하루 퀘스트 3가지로.

**리뷰에서 다시 확인한 방향**(`core-saju-review-plan.md` 4장)
| 리뷰 신호 | 이번 설계 |
|---|---|
| 짧은 운세를 매일 습관처럼, 광고·대기 없이 | 홈을 열면 오늘이 이미 펼쳐져 있음. 나머지는 한 줄짜리 작은 창 |
| 월운이 며칠부터 바뀌는지 모름 | 이달 창과 미션 ①에 절기 기간(예: 한로 10/8~11/6)을 표기 |
| 맞았는지 확인할 방법이 없음 | 미션 ②가 「어제 운세 맞았나요?」를 그 자리에서 묻고 기록함에 남김 |
| 기능을 찾기 어려움 | 미션 ③이 하루 한 가지씩 새 기능을 소개하고 엶(11단계) |
| 매일 부정적이면 기분 나쁨 | 미션 ①은 점수와 상관없이 오늘 할 좋은 행동 하나 |

**홈 순서**: 2027년(접힘) → ☀️ 오늘(펼침) → (이번 주) → 🌙 이달(작은 창) → 📅 올해(작은 창) → (대운·타고난 나) → ✅ 오늘의 미션 → 연 기능들

**오늘의 미션 3가지** (`js/daymission.js`)
1. 🌙 이달의 실천 — "이번 달은 「○○」의 기운" + 오늘의 행동 하나(액땜 미션). 「했어요」 → 액막이 부적 정화
2. 📒 돌아보기 — 어제 기록이 있으면 맞았어요·반반·아니었어요(+메모), 없으면 이달 가장 좋은 날 확인 / 오늘 점수 근거를 하루씩 번갈아
3. 🎁 새 기능 열기 — 길잡이 다음 단계(n/11). 다 열면 신수 카드·상담·질문·기록함을 번갈아
- 셋 다 하면 +5 EXP와 「내일 미리보기」(내일 점수·제목) → 다음 날 다시 올 이유
- 지금 할 차례인 미션 버튼만 강조색, 나머지는 보조 버튼 → 다음 순서가 눈에 보임
- 별도 카드였던 「다음 할 일」·「어제 운세」·「처음 일주일 안내」·「액땜 미션」은 이 카드 하나로 합침

## 8. v0.28 내년 운세 카드: 12칸 그래프 → 신년운세 구성

**문제**: 점수 눈금을 60점대로 맞춘 뒤 12달 막대가 대부분 비슷한 높이라 정보 없이 시선만 분산. 「2·3…12·1」 절기월 순서도 헷갈림. "내년에 뭐가 좋고, 뭘 조심하고, 언제 움직이나"에 바로 답하지 못함.

**참고한 리뷰 신호**: 점신 — 다음 해 신년운세를 가장 먼저 볼 수 있어서 남음 / 포스텔러 — 재미있는 무료 콘텐츠(18%) / "신년운세가 맞았는데 확인할 기능이 없다" / 기획 1장 G — 「총평 → 상·하반기 → 좋은 달」 표준 구성

**새 구성** (`js/yearcard.js`, 모든 값은 같은 엔진의 점수)
| 순서 | 구역 | 내용 |
|---|---|---|
| 접힘 | 그해 이름 + 키워드 | 「인정받고 자리 잡는 해」 · 올해 대비 · #인정 #승진·합격 #신뢰 |
| ① | 한 줄 총평 | 십신 해설 첫 문장 + 올해와 비교 |
| ② | 분야별 5칸 | 재물·애정·직장·건강·대인 별 1~5 + 한 줄 |
| ③ | 사계절 4칸 | 12달 → 4칸, 가장 좋은 계절 🌟 · 쉬어 가는 계절 🍵 |
| ④ | 꼭 기억할 달 3개 | 좋은 달 2 + 조심할 달 1, 절기월 기간(2/4~3/5)과 이유 |
| ⑤ | 행운 키트 | 색·숫자·방향·힘이 되는 띠·소품 |
| ⑥ | 다짐 한 줄 | 기록함 저장 → 그해 12월 미션 ②로 「얼마나 이뤘나요?」 |
| ⑦ | 12달 자세히 | 운세 풀이 화면의 표(기간·점수·그달 기운, 카드와 같은 🌟⚠️) |
