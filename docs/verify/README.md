# 용신·격국 검증 세트 (v0.35, 로드맵 E2)

엔진이 "다른 앱보다 분석이 못하지 않다"는 것을 숫자로 보여 주기 위한 정답 세트입니다.

## 순서
1. **질문지**: `expert-sheet.csv` (60명식 = 일간 10종 × 6개, 태어난 달 12개가 5개씩 고르게). 이름은 없고 네 기둥이 이미 계산돼 있습니다. 전문가는 **적힌 네 기둥만 보고** 판정합니다(경도 보정·자시 기준 차이를 없애기 위해).
2. **전문가 2명 이상**이 서로 모르게 `용신`·`희신`·`격국` 칸을 채웁니다. 오행은 목·화·토·금·수(한자·영어도 됨), 격국은 정관·편관(칠살)·정재·편재·식신·상관·정인·편인·건록·양인 등.
3. **성적 보기**: `cd saju-app && node tools/verify.mjs report 전문가A.csv 전문가B.csv`
   - 엔진 vs 전문가: 용신 일치 · 넓게 일치(엔진 용신·희신 중 하나가 전문가 용신) · 희신 · 격국
   - 전문가끼리 일치 = 엔진이 노릴 수 있는 상한선(학파마다 용신이 다르기 때문)
   - 기준값 맞추기: 앞 30명식으로 조후표 보완 기준(`TABLE_MILD`, 지금 10%)을 고르고 **뒤 30명식 성적만** 보고(과적합 방지)
4. 결과를 이 문서 아래 「기록」에 남기고, 기준값을 바꿨다면 `saju.js TABLE_MILD`와 테스트를 함께 고칩니다.
