## Q1. 캐릭터 진화: 몇 단계, 어떤 조건이 지루하지 않을까?

### 적용한 심리 원리

| 원리 | 뜻 | 프로토타입 적용 |
|---|---|---|
| 목표 근접 효과 | 목표에 가까울수록 더 열심히 한다 | 경험치 바와 "다음 진화까지 N레벨" 표시 |
| 호기심 간극 | 모르는 것을 알고 싶어 한다 | 다음 단계는 **검은 실루엣**으로만 공개 |
| 손실 회피 | 얻는 기쁨보다 잃는 아픔이 2배 크다 | 🔥 연속 출석 기록, 끊기면 알림 |
| 부여된 진척 | 이미 시작했다고 느끼면 끝까지 간다 | 첫날 출석+운세+미션만으로 Lv.2 도달 |
| 의례(세리머니) | 직접 누르는 순간이 기억에 남는다 | 진화는 자동이 아니라 **진화하기 버튼** + 빛나는 연출 |
| 가변 보상 | 예측 못 한 보상이 더 강하다 | 부적 등급 뽑기, 연속 출석 상자 |

### 단계 설계 (구현 완료)

| 단계 | 레벨 | 외형 | 매일 퀘스트만 할 때 도달 시점 |
|---|---|---|---|
| 1. 아기 수호령 | 1 | 작은 몸, 알 껍질, 턱받이 | 첫날 |
| 2. 견습 수호령 | 5 | 한복 + 고민 소품 | 약 2~3일 |
| 3. 수호 무사/선녀 | 10 | 망토 + 오행 구슬 2개 | 약 1주 (7일 스트릭 보상과 겹치게) |
| 4. 수호신 | 20 | 광륜 + 구름 + 오행 구슬 5개 | 약 3~4주 |
| 5. 신수(神獸) | 35 | 날개 + 금관 + 무지개 오라 | 약 2~3개월 |

설계 의도: 앞 단계는 빨리(첫 주에 2번 진화), 뒤 단계는 천천히. 초반 이탈을 막고, 장기 사용자에게는 "자랑할 거리"를 남긴다.

### 경험치 구조

- 일일 퀘스트 6개, 하루 최대 80 EXP (과몰입 방지 상한)
- 연속 출석 보너스: 하루 +2씩, 최대 +20
- 연속 보상: 3일 희귀 부적 / 7일 영웅 부적 + 스트릭 보호 부적 / 14일 전설 / 30일 신화 + 한정 칭호

### 다음 단계 추천

1. **진화 갈림길**: 4단계에서 "용신 루트(균형형)"와 "고민 루트(특화형)" 선택 → 같은 띠라도 다른 모습, 재플레이 가치
2. **주간 보스 액운**: 일요일마다 "액운 몬스터"를 부적 장착 스탯으로 물리치기 (협동형 이벤트로 확장 가능)
3. **되살리기 퀘스트**: 스트릭이 끊기면 3일 안에 미션 2개로 복구 (Duolingo "Earn Back" 방식)

## Q2. 친구 궁합 카드: 점수화와 공유 극대화

### 점수 공식 (제안)

```
궁합 점수 = 50
  + 띠 관계:  삼합(예: 申子辰) +20, 육합(子丑 등) +15, 충(子午 등) -10, 원진 -5
  + 일간 관계: 서로 상생(목→화) +12, 같은 오행 +6, 상극 -6
  + 오행 보완: 내가 가장 부족한 오행이 상대에게 많으면 +최대 12 (양방향 합산)
  + 하루 변동: 오늘 일진과 두 사람의 관계 ±5
→ 10~99로 제한, 결과는 5등급(천생연분/찰떡/좋은 친구/티격태격/밀당 중)
```

- 낮은 점수도 **재미있는 이름**으로 포장해야 공유된다 ("티격태격 케미 62점"). 낮은 점수를 "나쁨"으로 표시하면 공유가 끊긴다.
- 점수 근거(띠·오행)를 한 줄로 보여 주면 "왜?" 하고 다시 들어온다.

### 공유가 많이 일어나는 구성

| 요소 | 이유 |
|---|---|
| 두 캐릭터가 **함께 포즈** (손잡기·하이파이브·등 맞대기를 등급별로) | 사람은 "우리"를 보여 주는 이미지를 공유한다 |
| 친구는 생일만 넣으면 캐릭터가 **임시로 생성** | 친구가 앱을 깔지 않아도 결과가 나와야 초대 장벽이 없다 |
| 결과 카드에 "상대 캐릭터를 진짜로 받아 가기" 버튼 | 받은 사람이 자기 캐릭터를 만들러 들어온다 (초대 고리) |
| 둘이 함께 쓰는 **우정/커플 부적** | 한쪽만 장착하면 효과 반, 둘 다 장착하면 2배 → 상대 설치 동기 |

### 수익 연결 (Co-Star 방식)

- 무료: 궁합 점수 + 한 줄 요약 + 공유 카드
- 유료: 상세 궁합 리포트 (연애·일·돈 궁합, 올해 좋은 날) 2,900~4,900원
- 커플·우정 한정 꾸미기 세트 (커플 한복, 쌍가락지 소품)

## Q3. 꾸미기 상점: 무료와 유료의 경계

### 핵심 원칙

1. **능력치는 팔지 않는다.** 행운 수치를 돈으로 올리면 "돈 내면 운이 좋아진다"는 불쾌감과 과장 광고 논란이 생긴다. 실제 게임에서도 꾸미기가 지출의 과반이다.
2. **사주로 정해지는 기본 정체성은 무료.** 띠·오행·성별·고민으로 만든 캐릭터는 "나"이므로 잠그면 반감이 크다.
3. **노력으로 얻는 길을 항상 남긴다.** 유료 아이템 일부는 연속 출석으로도 얻을 수 있게 → 무료 사용자의 박탈감 감소 + 결제자의 "시간을 산다"는 명분.

### 무료 / 유료 구분 (제안)

| 구분 | 아이템 | 가격 |
|---|---|---|
| 무료 (기본) | 사주 캐릭터, 진화 5단계 외형, 표정 8종, 부적 일일 1장, 기본 테마 2종 | 0원 |
| 무료 (노력 보상) | 스트릭 보상 부적, 30일 한정 칭호, 시즌 무료 트랙 소품 | 0원 |
| 유료 단품 | 한복 색 변경, 장신구(노리개·비녀·갓), 배경(궁궐·네온 서울·달밤) | 1,200~3,300원 |
| 유료 세트 | 명절 한정 세트(설빔·추석빔), 12지신 탈 세트 | 4,900~7,900원 |
| 시즌 패스 | 4주, 무료 트랙 + 유료 트랙(꾸미기 10종, 프리미엄 부적 테마) | 5,900원 |
| 구독 | 매일 부적 +1, 광고 제거, 월간 리포트, 매달 한정 소품 1개 | 4,900원/월 |

### 결제 심리 장치 (적용 권장)

| 장치 | 설명 | 주의점 |
|---|---|---|
| 앵커링 | 비싼 세트 옆에 단품을 두면 단품이 싸 보인다 | 가격은 항상 원화로 표시 |
| 미리 입혀 보기 | 사기 전에 내 캐릭터에 입혀 본다 (보유 효과) | 미리보기는 무제한 무료 |
| 한정성 | 명절·시즌 한정 | "다시 안 나옴"은 지켜야 신뢰가 유지된다 |
| 첫 구매 할인 | 첫 결제 1,100원 스타터 팩 | 결제 경험 장벽을 낮추는 효과가 가장 크다 |
| 확률 공개 | 랜덤 상품은 확률과 천장(최대 비용)을 함께 표시 | 2024년부터 확률형 아이템 정보 공개 의무화 |

### 예상 매출 구조 (MAU 10만 가정, 참고용)

| 상품 | 가정 구매율 | 월 매출 |
|---|---|---|
| 시즌 패스 | 6% | 약 3,500만 원 |
| 꾸미기 단품·세트 | 3% × 평균 4,000원 | 약 1,200만 원 |
| 구독 | 2% | 약 980만 원 |
| 궁합 상세 리포트 | 1.5% × 3,900원 | 약 590만 원 |
| **합계** | | **약 6,300만 원** |

※ 구매율은 위 근거 자료의 하단 범위를 적용한 가정값이다.
