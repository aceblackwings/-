# 미래형 사주·부적 앱 기획서: 3가지 방향

> 작성일: 2026-11-01
> 범위: 3가지 기획 방향의 설계도 + 실제 유료 전환율(실구매비율) 비교 + 추가 아이디어
> 시장 수치는 공개 보도와 업계 리포트를 근거로 했고, 출처마다 기준이 다르므로 **방향을 잡는 참고값**으로 쓴다.

## 0. 세 방향에 공통으로 들어가는 기반

어느 방향을 고르든 아래 엔진은 같이 쓴다. 이 부분을 먼저 만들어 두면 방향을 바꾸거나 섞어도 다시 만들 필요가 없다.

### 0-1. 사주 엔진

| 모듈 | 입력 | 출력 | 구현 메모 |
|---|---|---|---|
| 만세력 변환 | 생년월일시, 양력/음력, 출생지(선택) | 연주·월주·일주·시주 (8글자) | 월주는 **절기 기준**으로 바꾼다. 23~01시 자시는 야자시/조자시 중 하나를 고르는 옵션을 둔다. 출생 시간을 모르면 삼주(6글자)로만 계산한다. 오픈소스 `lunar-javascript`(6tail)의 EightChar를 쓰거나 자체 테이블로 만든다 |
| 오행 분포 | 8글자 | 목·화·토·금·수 점수 (합계 100) | 천간 1.0, 지지 본기 1.0, 지장간 중기·여기 0.3~0.5 가중치. 태어난 달의 지지(월지)는 ×1.5 |
| 일간 강약 | 일간, 월지, 오행 분포 | 신강/중화/신약 + 용신 후보 | 처음 버전은 점수제로 단순화하고, 고급 풀이는 이후 업데이트에서 다듬는다 |
| 오늘의 기운 | 오늘 일진(날짜의 간지) + 사용자 일간 | 십신 관계, 합·충·형 여부 | 오늘의 운세 점수 계산에 쓴다 |
| 하루 고정 시드 | `hash(userId + 날짜)` | 0~1 난수 | 같은 날 앱을 다시 열어도 결과가 바뀌지 않게 하여 신뢰를 지킨다 |

### 0-2. 오늘의 운세 점수 공식 (예시)

```
카테고리 = [총운, 재물, 애정, 직장·학업, 건강, 대인]

기본점수[c]   = 50
십신보정[c]   = 표1[오늘 일진 천간과 내 일간의 십신][c]     // -20 ~ +20
합충보정[c]   = 오늘 일지와 내 원국 지지의 합(+8) / 충(-10) / 형(-6)
용신보정      = 오늘 일진 오행이 용신이면 +10, 기신(불리한 오행)이면 -10
변동폭        = (시드 - 0.5) × 10                              // ±5, 매일 같은 점수만 나오지 않게

점수[c] = clamp(기본 + 십신 + 합충 + 용신 + 변동, 5, 98)
```

- 표1 예시: 정재일에는 재물 +15, 편관일에는 직장 -8과 건강 -5.
- 결과 문장은 **점수 구간 × 십신 × 카테고리** 템플릿 조합에 생성형 모델로 다듬은 문장을 더한다. 문장은 사전에 만들어 캐싱해 비용을 낮춘다.

### 0-3. 부적 생성 엔진 (세 방향 공통)

```
부적 = {
  id, ownerId, createdAt,
  type:     "액막이" | "행운" | "재물" | "애정" | "합격" | "건강" | "이모티콘",
  element:  "목" | "화" | "토" | "금" | "수",       // 부족한 오행을 우선 배정
  rarity:   "일반" | "희귀" | "영웅" | "전설" | "신화",
  theme:    "전통주사" | "네온" | "픽셀" | "홀로그램" | "수묵",
  effects:  [{ stat: "행운", value: +12 }, { stat: "액운", value: -8 }],
  glyph:    { hanja: "招財進寶", symbolSet: "符頭-星紋-雲紋" },
  palette:  오행별 색상표,
  validUntil: 오늘 23:59 (일일 부적) | null (영구 소장)
}
```

**효과 수치 공식**

```
등급기본값   = { 일반: 5, 희귀: 8, 영웅: 12, 전설: 16, 신화: 20 } (%)
부족보정     = 1 + (20 - 내 오행점수[element]) / 40     // 부족할수록 효과가 커짐, 0.5~1.5
오늘보정     = 오늘 일진이 같은 오행을 도우면 1.2, 누르면 0.9
효과값       = round(등급기본값 × 부족보정 × 오늘보정)
```

> 예: 수(水) 점수가 6인 사용자가 '영웅' 수기 부적을 받은 날 일진이 금(金)이면(금생수)
> 12 × (1 + 14/40) × 1.2 = 12 × 1.35 × 1.2 ≈ **+19% 집중력**

**오행별 색상과 디자인 매핑**

| 오행 | 전통 테마 | 네온 테마 | 문양 모티프 |
|---|---|---|---|
| 목 | 청록 먹선 | #39FF88 형광 그린 | 넝쿨, 죽엽 |
| 화 | 경면주사 붉은색 | #FF2E63 마젠타 | 불꽃, 봉황 |
| 토 | 황토 | #FFC93C 앰버 | 산, 격자 |
| 금 | 은박 | #E0E0FF 크롬 화이트 | 칼, 별 |
| 수 | 먹 검정 | #00E5FF 사이언 | 물결, 거북 |

**렌더링 방식**
- 기본: SVG 템플릿 레이어 합성 (테두리 → 부두(符頭) → 주문 한자 → 문양 → 효과 배지 → 서명 낙관). 서버 비용이 거의 0원이고 즉시 생성된다.
- 프리미엄: 이미지 생성 API로 1점만 있는 일러스트 부적을 만든다. 장당 원가를 계산해 유료 상품에만 쓴다.
- 네온 효과: CSS/WebGL glow, 홀로그램 테마는 기기 기울기(자이로)에 반응하는 반사광.

### 0-4. 공통 기술 스택 (추천)

| 영역 | 1안 (빠른 출시) | 2안 (확장형) |
|---|---|---|
| 앱 | Flutter 또는 React Native (Expo) | 네이티브 iOS/Android |
| 백엔드 | Firebase (Auth, Firestore, Functions) | NestJS + PostgreSQL + Redis |
| 결제 | RevenueCat (구독과 단건 통합) | 동일 |
| 이미지 | 클라이언트 SVG 렌더 → PNG 내보내기 | 서버 렌더 + CDN |
| 문장 생성 | 템플릿 + 생성형 모델 사전 생성 캐시 | 실시간 대화형 풀이 |
| 분석 | Firebase Analytics + Amplitude | 동일 |

### 0-5. 개인정보와 고지 (공통 필수)

- 생년월일시는 암호화해 저장하고, 탈퇴하면 즉시 삭제한다. 계정 없이 기기에만 저장하는 모드도 둔다.
- "본 콘텐츠의 효과 수치는 재미를 위한 게임 요소입니다" 고지를 부적 상세 화면에 상시 노출한다.
- 유료로 랜덤 획득하는 구조를 넣으면 **획득 확률을 공개**한다. 2024년 3월 22일부터 게임산업법상 확률형 아이템 확률 공개가 의무화됐고, 앱의 법적 분류와 상관없이 같은 수준으로 공개하는 것이 안전하다.

## 방향 A. 「운명 RPG」: 오행 스탯 부적 컬렉션 게임

### A-1. 한 줄 콘셉트
> **"내 사주가 캐릭터 시트가 된다."** 사주 원국이 RPG 스탯창이 되고, 매일 부적을 모아 부족한 오행을 채우며 '운명 레벨'을 올린다.

### A-2. 타깃
- 1차: 20~34세, 수집형 게임과 MBTI·사주 콘텐츠를 즐기는 MZ세대
- 2차: 서브컬처 팬층 (캐릭터, 도감, 등급 문화에 익숙한 사용자)

### A-3. 하루 핵심 루프

```
[앱 실행] → [오늘의 운세 스탯 변화 확인]
   → [일일 부적 1장 무료 뽑기] → [장착 슬롯 3칸에 부적 배치]
   → [오늘 스탯 완성: 행운 +18%, 액운 -12%]
   → [저녁: 오늘 하루 체크인] → [경험치·조각 획득]
   → [조각 10개 = 상위 등급 합성] → [도감 채우기] → 다음 날
```

### A-4. 화면 구성도 (IA)

```
홈 (운명 스탯창)
├── 캐릭터 카드: 일간(예: 甲木)을 수호령 캐릭터로 표현
├── 오행 레이더 차트 (원국 + 오늘 장착 효과 반영)
├── 오늘의 운세 6개 카테고리 게이지
└── 장착 슬롯 3칸

부적 뽑기
├── 무료 일일 뽑기 (1회)
├── 광고 보고 추가 뽑기 (하루 2회)
├── 유료 뽑기 (확률표 버튼을 상단에 노출)
└── 천장(pity) 게이지: 50회 안에 전설 1장 보장

도감
├── 오행 × 종류 × 테마 매트릭스 (예: 5 × 6 × 5 = 150종)
├── 시즌 한정 (입춘, 동지, 수능, 설날)
└── 완성 보상: 테마 해금, 칭호

합성·강화
├── 같은 부적 3장 → 등급 상승
└── 강화 확률 공개, 실패해도 조각 반환

프로필
├── 운명 레벨, 칭호, 대표 부적
└── 친구 운명 카드 방문 (궁합 점수 표시)
```

### A-5. 주요 기능 명세

| 기능 | 상세 | 우선순위 |
|---|---|---|
| 사주 스탯창 | 오행 5스탯 + 파생 스탯(행운, 재물, 매력, 집중, 체력, 액운저항) | P0 |
| 일일 부적 | 하루 고정 시드로 결정. 부족한 오행이 나올 확률 가중치 2배 | P0 |
| 장착 슬롯 | 기본 3칸, 레벨 10에 4칸 해금 | P0 |
| 확률 공개 뽑기 | 일반 60 / 희귀 28 / 영웅 9 / 전설 2.7 / 신화 0.3 (%) | P1 |
| 천장 시스템 | 50회 전설 확정, 다음 시즌으로 이월 | P1 |
| 시즌 패스 | 4주 단위, 무료 트랙과 유료 트랙 | P1 |
| 친구 궁합 레이드 | 친구 2~4명의 오행을 합산해 '파티 운세' 제공 | P2 |

### A-6. 수익 모델과 가격

| 상품 | 가격 (안) | 비고 |
|---|---|---|
| 복전(福錢) 재화 | 1,200원 ~ 59,000원 6단계 | 유료 뽑기용 |
| 시즌 패스 | 5,900원 / 4주 | 매출의 핵심 기둥 |
| 월정액 '수호령 계약' | 4,900원 / 월 | 매일 뽑기 +1, 광고 제거 |
| 보상형 광고 | 하루 최대 3회 | 결제하지 않는 사용자에게서 나는 수익 |

### A-7. KPI 목표

| 지표 | 목표 | 근거 |
|---|---|---|
| D1 / D7 / D30 리텐션 | 40% / 18% / 8% | 캐주얼 수집형 게임 평균 수준 |
| 결제 사용자 비율 (MAU 대비) | 3~6% | Xsolla 2025: RPG 결제 성공률 7.2% (아래 비교표 참고) |
| ARPPU (결제자 1인당 월 매출) | 9,000~15,000원 | 패스와 소액 뽑기 중심으로 고래 의존을 줄인다 |

### A-8. 강점과 리스크
- 강점: 리텐션 장치가 가장 강하고, 부적을 게임 아이템처럼 보여주는 차별점이 가장 확실하다.
- 리스크: 확률형 아이템 규제와 여론, 게임처럼 보여서 앱 심사에서 게임으로 분류될 가능성, 콘텐츠(도감)를 계속 만들어야 하는 운영 부담.

## 방향 B. 「네온 부적 스튜디오」: 만들고 공유하는 크리에이터형

### B-1. 한 줄 콘셉트
> **"오늘의 나만의 부적과 이모티콘을 디자인해서 자랑한다."** 사주 결과를 재료로 전통부터 사이버펑크 네온까지 원하는 스타일의 부적, 행운 이모티콘, 배경화면을 만들어 SNS와 메신저로 퍼뜨린다.

### B-2. 타깃
- 1차: 인스타그램 스토리와 카카오톡을 많이 쓰는 18~30세, 꾸미기를 좋아하는 사용자
- 2차: 해외 K-컬처 팬 (한자와 부적의 이국적인 매력)

### B-3. 핵심 루프

```
[오늘의 운세 확인] → [AI 추천 부적 시안 3개]
   → [스튜디오에서 꾸미기: 테마, 색, 문구, 효과 배지]
   → [내보내기: 스토리 카드 / 잠금화면 / 위젯 / 이모티콘 세트]
   → [공유 링크로 친구 유입: "너도 오늘의 부적 받아봐"]
   → [친구가 가입하면 둘 다 프리미엄 테마 1일권]
```

### B-4. 화면 구성도

```
홈
├── 오늘의 운세 요약 카드 (스와이프하면 상세)
├── 추천 부적 3장 (전통 / 네온 / 랜덤 테마)
└── 오늘의 행운 이모티콘 (자동 생성 1종)

스튜디오 (에디터)
├── 레이어: 배경 → 테두리 → 부두 → 주문 → 문양 → 효과 배지 → 낙관
├── 테마 팩: 전통주사, 네온 서울 2099, 픽셀 레트로, 홀로그램, 수묵
├── 문구 입력: "오늘 발표 대박" → 한자 주문 자동 추천 (예: 言出必成)
├── 효과 배지 편집: 사주 근거 범위 안에서만 수치 선택
└── 애니메이션: 네온 깜빡임, 홀로그램 반짝임 (GIF/MP4 내보내기)

내보내기
├── 인스타 스토리 9:16 (공유 링크 스티커 포함)
├── 잠금화면 배경, 홈 위젯
├── 메신저 이모티콘 세트 (8~16종 자동 확장)
└── 실물 굿즈 주문 (키링, 스티커, 카드)

갤러리
├── 내 작품, 좋아요, 인기 부적 피드
└── 크리에이터 템플릿 마켓 (2단계 기능)
```

### B-5. 오늘의 행운 이모티콘 생성 규칙

```
기본 캐릭터 = 일간 수호령 (甲=푸른 사슴, 丙=불꽃 여우, 戊=황토 곰, 庚=은빛 매, 壬=검은 거북 … 10종)
오늘 표정   = 총운 점수 구간 (80+ 신남 / 60+ 미소 / 40+ 담담 / 40- 결연)
소품        = 오늘 최고 카테고리 (재물→엽전, 애정→하트 부채, 직장→붓)
문구        = "재물운 +15%", "액운 차단 완료" 같은 게임식 짧은 문구
스타일      = 사용자가 선택한 테마
```

- 하루 1종은 무료로 주고, 같은 캐릭터의 8종 세트(기쁨, 감사, 화이팅, 졸림 등)는 유료로 판다.

## 방향 C. 「데일리 액땜 코치」: 루틴과 웰니스형 구독 서비스

### C-1. 한 줄 콘셉트
> **"운세를 읽는 데서 끝내지 않고, 운을 관리하는 습관으로."** 매일 아침 운세와 액땜 미션을 주고, 저녁에 하루를 돌아보며, 한 달 뒤 '나의 운 리포트'로 내 패턴을 보여주는 운 관리 코치.

### C-2. 타깃
- 1차: 25~45세 직장인. 불안을 관리하고 마음을 안정시키고 싶은 사용자
- 2차: 수험생, 이직 준비생 등 중요한 시기를 지나는 사용자

### C-3. 핵심 루프

```
[아침 알림 07:30] → [오늘의 운세 + 오늘의 액운 1개 + 행운 행동 1개]
   → [액땜 미션 수락: "오전에 먼저 인사 3번"]
   → [미션 완료 체크 → 액땜 부적 '정화 완료' 애니메이션]
   → [밤 21:30 회고: 오늘 운세 적중도 별점 + 한 줄 일기]
   → [주간·월간 리포트: 어떤 일진에 컨디션이 좋았는지 패턴 분석]
```

### C-4. 화면 구성도

```
오늘
├── 아침 브리핑 카드 (30초 안에 읽히는 분량)
├── 액땜 미션 1~3개 (난이도 표시)
├── 행운 키트: 행운의 색, 숫자, 방향, 음식, 시간대
└── 오늘의 부적 (미션을 끝내면 강화됨)

기록
├── 캘린더 (일진 + 내 별점 + 기분 이모지)
├── 운세 적중도 그래프
└── 한 줄 일기

리포트 (구독 전용)
├── 월간 나의 운 리포트: 잘 맞은 십신·일진 패턴
├── 다가올 30일 중요한 날 (계약, 면접, 고백하기 좋은 날)
└── 대운·세운 타임라인

코치 대화
├── 오늘 고민을 물어보는 대화형 풀이 (하루 무료 3회)
└── 1:1 전문가 상담 연결 (수수료형)
```

### C-5. 액땜 미션 설계

| 오늘의 액운 (원인) | 미션 예시 | 완료 보상 |
|---|---|---|
| 겁재일, 금전 손실 주의 | "오늘은 충동구매 0회" | 재물 방패 부적 +10% |
| 편관일, 상사 압박 | "보고 전에 3번 심호흡" | 관재 차단 부적 |
| 일지 충, 이동 사고 주의 | "평소보다 10분 일찍 출발" | 안전 부적 |
| 상관일, 말실수 주의 | "칭찬 3번 먼저 하기" | 구설 차단 부적 |

- 미션은 **5분 안에 할 수 있고 실제로 도움이 되는 행동**으로만 만든다. 부적은 미신을 부추기는 도구가 아니라 습관을 만드는 보상이 된다.
- 연속 달성(스트릭) 7일이면 '수호 부적', 30일이면 '신화 부적'.

### C-6. 수익 모델과 가격

| 상품 | 가격 (안) | 비고 |
|---|---|---|
| 프리미엄 구독 | 6,900원 / 월, 49,000원 / 년 | 월간 리포트, 길일 캘린더, 대화 무제한 |
| 무료 체험 | 14~30일 | RevenueCat 2026: 체험 기간 17~32일의 유료 전환 42.5%, 4일 이하는 25.5% |
| 심층 리포트 단건 | 9,900원 | 신년운세, 이직운, 연애운 상세 (하드 페이월) |
| 전문가 상담 중개 | 수수료 30% | 점신 매출의 큰 비중이 유료 상담 |

### C-7. KPI 목표

| 지표 | 목표 | 근거 |
|---|---|---|
| 아침 알림 열람률 | 35% 이상 | 루틴형 앱의 생명선 |
| 30일 리텐션 | 15% | 습관형 앱이라 A·B보다 높게 잡는다 |
| 프리미엄 유료 비율 (MAU 대비) | 2~4% | RevenueCat 2026: 프리미엄 앱 D35 전환 중앙값 2.1% |
| 연간 구독 비중 | 40% 이상 | 매출 예측이 쉬워지고 이탈이 줄어든다 |

### C-8. 강점과 리스크
- 강점: 결제자 1인당 평생 가치(LTV)가 가장 높고, 매출이 안정적이며, 브랜드 신뢰도가 가장 좋다. 규제 리스크가 가장 낮다.
- 리스크: 첫인상이 수수해서 초기 바이럴이 약하다. 회고 기록이 쌓여야 가치가 생기므로 첫 달 이탈을 막는 장치가 필요하다.

### 4-3. 결론과 추천: 「B로 시작해 A를 붙이고 C로 수익을 굳힌다」

1. **1단계 (0~3개월) B 중심 출시:** 네온·전통 부적과 오늘의 이모티콘을 공유하는 데 집중한다. 광고비 없이 사용자를 모으고, 화제성을 확보한다.
2. **2단계 (3~6개월) A의 도감과 등급 결합:** 공유로 들어온 사용자를 매일 돌아오게 만든다. 유료 랜덤 뽑기보다 **시즌 패스 위주**로 규제 리스크를 낮춘다.
3. **3단계 (6~12개월) C의 구독과 리포트:** 쌓인 기록으로 월간 리포트를 팔고, 연간 구독으로 안정적인 매출 기반을 만든다.
