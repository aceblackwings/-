# 12지신 수호 캐릭터 디자인 업그레이드 방향

> 작성일: 2026-11-01 · 대상: 운명공방 2099 프로토타입 v0.6

---

## 1. 조사에서 얻은 원칙

| 원칙 | 근거 | 현재 상태 | 업그레이드 방향 |
|---|---|---|---|
| **실루엣만 봐도 누군지 알아야 한다** | 강한 실루엣은 작은 썸네일에서도 읽힌다 (캐릭터 디자인 가이드 다수) | 귀·뿔·꼬리로 12띠 구분 | 띠마다 "대표 실루엣 1개"를 과장 (토끼 귀 1.3배, 용 뿔 더 크게, 닭 볏 더 크게) |
| **둥근 형태 = 친근함** | 원은 친근하고 안전하고 귀여운 인상 | 머리·몸 모두 원형 | 유지. 진화 후반에만 각진 장식(갑옷·왕관)을 더해 "강해짐"을 표현 |
| **머리 비율 1~3등신** | 치비 비율은 1~3등신, 몸이 짧고 통통할수록 귀엽다 | 약 1.8등신 | 아기 단계는 1.5등신, 신수 단계는 2.2등신으로 단계별 비율 차이 |
| **시각적 보상이 노력과 맞아야 한다** | 오래 키웠는데 글자만 바뀌면 실망한다 (펫 게임 개발 사례) | v0.6에서 단계별 크기·배경·장비 강화 | 단계마다 "새 애니메이션 1개" 추가 (예: 3단계 망토 휘날림) |
| **단계마다 새 기능이 열려야 한다** | 성장 단계별로 새 상호작용·능력이 열리는 구조 (디지털 펫 사례) | v0.6에서 슬롯·능력치 해금 | 단계별 "특기" 추가 (4단계: 하루 한 번 부적 등급 +1) |
| **반응하는 캐릭터에 애착이 생긴다** | 펫이 고유하게 반응하고 책임감을 느끼면 계속 돌아온다 | 표정 8종, 눈 깜빡임, 숨쉬기 | 탭하면 반응, 오래 안 오면 시무룩, 미션 완료 시 기뻐하는 모션 |
| **일관된 세계관과 성격** | 잔망루피 등 국내 IP: 흔들림 없는 세계관과 성격이 팬덤의 핵심 | 이름·칭호만 있음 | 띠별 성격·말투 설정 (호랑이: 허세 있는 의리파, 토끼: 수다쟁이) |
| **귀여움 + 개성** | MZ세대는 귀여움에 반응하고, 개성이 있으면 더 좋다는 분석 | 귀여움 위주 | 살짝 "망가진" 표정, 엉뚱한 소품 등 개성 포인트 |
| **캐릭터가 구매 결정에 영향** | 구매 시 캐릭터가 영향을 준다는 응답 64.2% (한국콘텐츠진흥원 조사 인용) | - | 굿즈(키링·스티커) 연결 시 캐릭터 완성도가 매출로 직결 |

## 2. v0.6에서 바로 적용한 것

- **단계별 몸 크기**: 아기 0.7배 → 견습 0.86배 → 수호 0.94배 → 수호신·신수 1.0배
- **단계별 배경 무대**: 파스텔 아기방 → 밤하늘 → 보랏빛 사당 → 노을 구름과 회전하는 팔괘 → 우주와 무지개 고리
- **단계별 장비**: 알껍질 모자 → 한복과 소품 → 망토·금빛 어깨갑옷·오행 문장·마법진 → 광륜·구름·금빛 테두리·오행 구슬 5개 → 날개·영험한 꼬리 3개·이마 보석·금관·반짝이 입자
- **살아 있는 느낌**: 눈 깜빡임, 숨쉬듯 위아래로 움직이기 (아기는 더 빠르게)
- **입체감**: 머리 하이라이트와 아래쪽 그림자
- **해금 보상**: 이모티콘 슬롯(Lv.5), 부적 2번째 슬롯(Lv.10), 단계마다 능력치 +6, 행운력 +10

## 3. 다음 업그레이드 추천 (우선순위 순)

### ① 띠별 성격과 말투 (비용 낮음, 효과 큼)
- 12띠 × 대사 30개 정도로 시작. 캐릭터를 누르면 말풍선으로 오늘 운세를 띠의 말투로 전달
- 예) 호랑이: "어흥! 오늘 재물운 72점이다. 지갑 단속은 내가 책임진다!"
- 효과: 같은 운세라도 "내 캐릭터가 말해 줬다"는 애착이 생김

### ② 반응 애니메이션 3종 (비용 중간)
- 탭: 깜짝 놀라며 점프 / 미션 완료: 만세 / 3일 미접속: 시무룩하게 앉아 있음 (부정 피드백도 감정을 만든다는 다마고치 설계 원칙)

### ③ 단계별 비율 변화 (비용 중간)
- 아기 1.5등신(머리 더 크게) → 신수 2.2등신(몸이 길어짐). 같은 캐릭터인데 "자랐다"는 체감이 가장 강함

### ④ 진화 갈림길 (비용 높음)
- 4단계에서 "용신 루트"와 "고민 루트" 중 선택 → 같은 띠라도 외형이 2갈래. 친구와 비교하는 재미

### ⑤ 전문 일러스트레이터와 협업 (비용 높음, 정식 출시 전 권장)
- 지금의 코드로 그린 캐릭터는 **조합 구조(띠×오행×성별×고민×단계)를 검증하는 시안**
- 정식 버전은 띠별 기본 원화 12종 + 부위별 파츠(옷·소품·장비)를 일러스트레이터가 그리고, 앱은 지금처럼 파츠를 조합하는 방식이 효율적
- 파츠 조합 방식이면 12띠 × 단계 5 × 옷 5 × 소품 9 = 2,700가지가 넘는 모습을 일러스트 수백 장으로 만들 수 있음

### ⑥ 굿즈 연결
- 내 캐릭터(진화 단계·장착 부적 포함)를 그대로 아크릴 키링·스티커로 주문
- 망그러진 곰처럼 굿즈·팝업이 팬덤을 키우는 사례가 많음
