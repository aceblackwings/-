## 0. 설계 근거 요약

| 근거 | 내용 | 설계에 주는 의미 |
|---|---|---|
| 카카오톡 선물하기 | 2025년 이용 1억 8,950만 건, 선물 약 2억 개 (보도) | 한국 사용자에게 **"작은 선물을 보내는 행동"은 이미 습관** → 부적 선물하기가 자연스럽다 |
| 스냅챗 스트릭 연구 | 연속 기록 참여는 스마트폰 과사용·FOMO(놓칠까 봐 불안)와 약한 관련. 청소년들이 "너무 지친다", "부담"이라고 표현 | 우정 스트릭은 **끊겨도 벌이 없게**, 회복 장치 필수 |
| 모바일 소셜 게임 연구 | 몰입한 플레이어일수록 친구 초대 의향이 높다 | **혼자 재미 → 함께 재미** 순서로 기능을 연다 |
| 초대 보상 현장 실험 | 가입 시 보상은 초대가 적지만 질이 높고, 공유만 해도 주는 보상은 많지만 질이 낮다 | 공유에는 작은 보상, **실제 가입에는 큰 보상** |
| 동물의 숲 꿈 번지 | 코드로 방문, 구경만 가능, 주인이 오프라인이어도 방문 가능, 비공개 전환 가능 | **코드 기반·읽기 전용·저장본 방문** 구조 |
| Co-Star | 친구 차트 비교가 바이럴과 유료 리포트로 연결 | 궁합은 무료로 퍼뜨리고 **상세 리포트는 유료** |

## 1. 소셜 구조 한눈에 보기

```
            ┌──────────── 1:1 관계 ────────────┐
 나 ── 수호 코드 ── 친구 (방문·응원·선물·함께 미션·우정 스트릭)
  │
  ├── 소모임 (2~12명): 단톡 궁합방, 팀 부적, 그룹 리포트
  │
  └── 띠 커뮤니티 (12개 띠 리그): 주간 협동 목표, 띠 축제
```

| 층 | 목적 | 핵심 기능 |
|---|---|---|
| **1:1 친구** | 애착과 재방문 | 방문, 응원, 부적 선물, 함께 미션, 우정 스트릭 |
| **소모임** | 바이럴 (단톡방 확산) | 단톡 궁합방, 오늘의 행운 멤버, 팀 부적 |
| **띠 커뮤니티** | 소속감과 정체성 | 12띠 리그 주간 협동 목표, 띠 축제 |

## 2. 1:1 친구 기능

### 2-1. 수호 코드와 친구 맺기
- 가입하면 8자리 **수호 코드** 발급 (예: `TG-7K2P-QX`). 생년월일·이름 대신 코드로 연결
- 친구 맺기 방법: ① 코드 입력 ② 초대 링크 ③ 궁합 카드의 "진짜 캐릭터 받기" 버튼
- **상호 수락제**: 한쪽이 요청하고 다른 쪽이 수락해야 연결
- 언제든 코드 재발급, 비공개 전환, 친구 끊기, 차단

### 2-2. 공개 카드 (방문하면 보이는 것)
| 공개 | 비공개 (절대 노출 안 함) |
|---|---|
| 띠·캐릭터 외형·진화 단계·장착 부적·칭호 | 생년월일·태어난 시간·사주 원국 |
| 오늘의 한마디(캐릭터 대사) | 고민 내용, 오늘 운세 점수 |
| 도감 진행도(예: 7/12) | 친구 목록, 실명 |

- 공개 카드는 **하루 1회 저장본**으로 갱신 → 상대가 접속하지 않아도 방문 가능, 접속 상태는 노출하지 않음

### 2-3. 방문과 응원
- 친구 캐릭터 방에 들어가면 **띠끼리 대화(144 조합 + 전설 30쌍)**가 자동 재생
- **응원하기**: 하루 1회, 상대 캐릭터 경험치 +5, 응원한 나도 +2
- **방명록**: 자유 글 대신 **정해진 스티커 24종**(이모티콘 세트 표정 + "시험 대박!", "힘내!" 등)
- 효과: 자유 채팅이 없어 괴롭힘·스팸·개인정보 노출 위험이 낮음

### 2-4. 부적 선물하기
| 종류 | 가격 | 내용 |
|---|---|---|
| 응원 부적 | 무료 (하루 1장) | 내 도감의 일반 부적 1장을 친구에게 |
| 맞춤 부적 | 990~2,900원 | 친구의 고민(시험·취업·건강 등)을 고르면 **친구의 부족한 오행으로** 만든 부적 + 카드 메시지 스티커 |
| 기념일 부적 세트 | 4,900원 | 생일·수능·면접 날짜에 맞춰 예약 발송 |

- 받은 친구의 부적 공방에 "○○가 보낸 부적" 표시, 장착하면 보낸 사람 이름이 부적 아래 새겨짐
- 친구의 생일은 **친구가 공개를 허락한 경우에만** 알림

### 2-5. 함께 미션 (협동)
- 두 사람에게 같은 액땜 미션 (예: "오늘 서로에게 칭찬 한마디 보내기")
- **둘 다 완료하면** 우정 부적 등급 +1, 혼자만 하면 보상 절반
- 경쟁이 아니라 **함께 성공**하는 구조

### 2-6. 우정 스트릭 (부담 없는 버전)
| 스냅챗식 (피함) | 운명공방식 |
|---|---|
| 24시간 안에 안 하면 0으로 초기화 | **주 단위**: 일주일에 3번 이상 응원하면 1주 연속 |
| 끊김 = 우정이 식은 것처럼 느껴짐 | 끊겨도 **"인연의 실" 장식만 잠시 흐려짐**, 다음 주에 바로 회복 |
| 숫자 경쟁 | 숫자 대신 **인연의 실 색깔** (흰색 → 빨간 실 → 금실 → 무지개 실) |

## 3. 소모임 기능 (단톡방 바이럴 엔진)

### 3-1. 단톡 궁합방
1. 방장이 "궁합방 만들기" → 초대 링크를 단톡방에 공유
2. 멤버가 링크를 누르면 **가입 없이** 띠·생일만 입력하고 참여 (기기 저장 원칙은 그대로, 방 안에는 띠·캐릭터만 공유)
3. 결과 화면:
   - **팀 궁합 지도**: 멤버들을 원형으로 놓고 삼합·육합은 실선, 충은 번개선
   - **오늘의 행운 멤버**: 오늘 일진과 가장 잘 맞는 1명 ("오늘 점심 메뉴는 ○○가 정해!")
   - **찰떡 듀오 / 티격태격 듀오**: 가장 높은·낮은 궁합 쌍
   - **팀 오행 밸런스**: 팀 전체에 부족한 오행 → "팀 부적" 추천
4. 결과를 **한 장짜리 이미지**로 단톡방에 다시 공유 → 확산 고리

### 3-2. 팀 부적
- 팀에 부족한 오행으로 만든 부적, 멤버 전원이 장착하면 팀 효과
- 시험 스터디, 회사 팀, 동아리, 가족 단위로 사용

### 3-3. 그룹 상세 리포트 (유료)
- "우리 팀 올해 운세 흐름", "커플 100일 궁합" 등 2,900~6,900원

## 4. 띠 커뮤니티: 12띠 리그

- 모든 사용자는 자기 띠 리그에 자동 소속 (예: 호랑이 리그)
- **주간 협동 목표**: "이번 주 호랑이 리그 액땜 미션 10만 회 달성" → 리그 전원에게 한정 장식
- **띠 축제**: 해당 띠의 해(예: 2026 병오년 = 말의 해)에 그 띠 리그 특별 이벤트
- **순위표는 만들지 않음**: 리그끼리 순위를 매기지 않고 목표 달성 여부만 표시 → 비교 스트레스 감소
- 리그별 응원 구호, 대표 대사를 사용자 투표로 선정 (팬 참여형 콘텐츠)

## 5. 안전과 개인정보

| 항목 | 정책 |
|---|---|
| 친구 정보 | 친구 생일은 **내 기기에만** 저장. 서버에는 친구 본인이 가입·동의했을 때만 |
| 공개 범위 | 공개 카드 항목만 서버 저장 (띠·외형·부적·칭호·한마디) |
| 소통 방식 | 자유 채팅 없음. 정해진 스티커·대사만 |
| 차단·신고 | 친구 끊기, 차단, 코드 재발급, 신고 버튼 |
| 미성년자 | 14세 미만은 보호자 동의 절차, 선물 결제 제한 |
| 알림 | 응원·선물만 기본 켜짐, 하루 최대 3개, 밤 10시~오전 8시 무음 |
| 근거 | 생년월일도 다른 정보와 결합하면 개인정보가 될 수 있고, 남의 정보를 서버로 넘기면 제3자 제공 규정(개인정보보호법 제17조)을 검토해야 함 → 정식 출시 전 개인정보 처리방침 작성과 전문가 검토 필수 |

## 6. 데이터 구조 (서버 최소화안)

```
users        : id, guardian_code, zodiac, stage, title, public_card_json, card_updated_at, is_private
friendships  : user_a, user_b, status(pending/accepted/blocked), weekly_cheer_count, thread_color
cheers       : from_user, to_user, date, sticker_id
gifts        : from_user, to_user, talisman_json, paid(bool), scheduled_at, opened_at
group_rooms  : id, owner, invite_token, created_at, expires_at
group_members: room_id, member_token, zodiac, display_name, character_json   ← 생일 원본은 저장하지 않음
league_goals : zodiac, week, target, progress
```

- **저장하지 않는 것**: 생년월일 원본, 태어난 시간, 사주 원국, 고민
- 사주 계산은 지금처럼 **각자 기기에서** 하고, 서버에는 결과(띠·캐릭터 외형)만 보냄

### 추천 기술 구성 (비용 최소)
| 영역 | 추천 | 이유 |
|---|---|---|
| 서버·DB | Supabase 또는 Firebase | 무료 구간으로 초기 운영 가능, 인증·DB·저장소 일체형 |
| 공개 카드 이미지 | 기기에서 SVG → PNG로 만들어 업로드 | 서버 그리기 비용 0 |
| 주간 리그 집계 | 하루 1회 예약 작업 | 실시간 처리 불필요 |
| 결제 | RevenueCat + 앱스토어 결제 | 선물·구독 통합 관리 |

## 7. 측정 지표

| 지표 | 정의 | 목표 (가정) |
|---|---|---|
| K-팩터 | 사용자 1명이 데려오는 신규 가입자 | 0.6 이상 |
| 소셜 사용자 비율 | 친구 1명 이상 연결된 사용자 / 전체 | 40% |
| D7 재방문 차이 | 친구 있는 사용자 vs 없는 사용자의 7일째 재방문율 | +10%p 이상 |
| 응원 왕복률 | 응원 받은 사람이 24시간 안에 답례 응원한 비율 | 50% |
| 선물 전환율 | 선물하기 화면 방문 중 유료 결제 | 5% |
| 궁합방 확산 | 궁합방 1개당 참여 인원 | 평균 5명 |

- 초대 링크에는 **무작위 토큰**만 넣고 개인정보는 넣지 않음. "토큰 클릭 → 가입" 수만 집계

## 9. 단계별 출시 로드맵

| 단계 | 기간 | 기능 | 서버 |
|---|---|---|---|
| **0 (현재)** | 완료 | 기기 안 친구 궁합, 수집 도감, 띠끼리 대화, 스토리 카드 | 없음 |
| **1** | 4~6주 | 수호 코드, 공개 카드, 방문, 응원·스티커 방명록 | 최소 서버 |
| **2** | +4주 | 단톡 궁합방 (가입 없이 참여), 팀 궁합 지도 이미지 | 방 토큰 |
| **3** | +4주 | 부적 선물(무료→유료), 함께 미션, 우정 스트릭 | 결제 연동 |
| **4** | +6주 | 12띠 리그 주간 협동 목표, 띠 축제 | 예약 집계 |

**가장 먼저 만들 것은 2단계 "단톡 궁합방"을 추천합니다.** 한국의 단톡방 문화에서 한 명이 만들면 5~10명이 동시에 들어오는 구조라서, 초대 효율이 가장 높습니다.
