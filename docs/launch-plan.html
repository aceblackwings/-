12지신 강림 웹·앱 동시 출시 실행 계획

작성일 2026년 11월 5일 · 대상: 대표(직접 할 일) · 기준 버전 v0.50.6

한눈에 보는 결론

목표일은 2026년 12월 22일(화, 동지)입니다. 웹, 안드로이드, iOS를 같은 날 공개합니다. 신년운세 검색이 늘어나는 12월 하순에 맞추고, 앱 안의 동지 계절 행사와도 이어집니다.

동시 출시가 가능한 조건은 두 가지입니다. 첫째, 계정 로그인과 구매 기록 서버가 먼저 있어야 웹에서 산 풀이를 앱에서도 볼 수 있습니다. 둘째, 구글 플레이 신규 개인 계정은 테스터 12명이 14일 동안 참여하는 비공개 테스트를 통과해야 정식 출시를 신청할 수 있으므로, 늦어도 11월 27일(금)에는 테스트를 시작해야 합니다.

추천 구성은 다음과 같습니다.

  • 앱 포장: Capacitor(지금의 정적 웹 코드를 그대로 쓰고, 인앱 결제와 알림은 앱 기능으로 붙임)
  • 서버: Firebase(로그인, 데이터 저장, 결제 승인 함수, 웹 호스팅)
  • 결제: 웹은 토스페이먼츠 또는 포트원, 앱은 각 스토어 인앱 결제
  • 개인정보: 생년월일과 사주 원본은 지금처럼 기기에만 두고, 서버에는 계정 번호와 구매 기록만 저장

심사 반려나 서류 지연으로 앱이 늦어지면, 웹은 12월 22일에 먼저 열고 앱은 승인되는 날 바로 공개하는 방식으로 전환합니다. 이 경우에도 계정과 구매 기록 구조는 같으므로 추가 작업은 없습니다.

먼저 정해 주실 것

아래 여섯 가지가 정해져야 서류와 개발이 동시에 움직일 수 있습니다. 추천안을 먼저 적었습니다.

결정 사항추천안다른 선택지와 차이
사업자 형태개인사업자, 일반과세자간이과세자는 부가세 부담이 적고 통신판매업 신고가 면제되지만, 개발비·광고비의 매입세액 공제가 제한됩니다. 첫해 매출이 작을 것으로 보면 간이과세도 가능합니다.
개발자 계정 종류애플·구글 모두 개인 계정조직 계정은 D-U-N-S 번호 발급(최대 30일)이 필요해 12월 출시에 맞추기 어렵습니다. 대신 스토어 판매자 이름이 대표 실명으로 표시됩니다. 법인 전환 후 조직 계정으로 옮길 수 있습니다.
로그인 방식구글 로그인 + 애플 로그인(필수) + 카카오 로그인(선택)iOS에서 구글이나 카카오 로그인을 넣으면 애플 로그인 같은 개인정보 보호형 로그인도 함께 제공해야 합니다. 로그인 없이 쓰다가 결제할 때만 로그인하게 하면 처음 들어오는 사람의 부담이 줄어듭니다.

가입 나이만 14세 이상만 가입만 14세 미만을 받으면 법정대리인 동의 절차를 만들어야 합니다. 쉬운 모드의 아이 추천(16세 이하)은 보호자 기기에서 쓰는 흐름으로 안내합니다.
AI 수호신 상담출시판에 포함, 하루 횟수 제한빼면 서버 비용이 들지 않지만 애플 심사에서 내세울 고유 기능 하나가 줄어듭니다. 넣으면 신고 기능과 비용 상한 설정이 필요합니다.

주차별 할 일

각 단계에 담당을 적었습니다. 「대표」는 직접 하셔야 하는 일이고, 「개발」은 이 작업 창에서 진행할 일입니다. 개발 작업은 대표님의 서류 작업과 같은 주에 나란히 진행됩니다.

1주차 (11월 9일~15일): 계정과 사업자 기초

  1. 사업자 등록(대표, 1~3일). 홈택스에서 신청합니다. 준비물: 신분증, 공동·금융 인증서, 사업장 주소(자택 가능, 임대 시 임대차계약서). 업태는 정보통신업, 종목은 응용 소프트웨어 개발 및 공급업, 부업종으로 전자상거래 소매업(통신판매)을 함께 넣습니다. 상호는 앱 이름과 달라도 됩니다.
  2. 사업용 통장 개설과 카드 등록(대표, 1일). 사업자등록증이 나오면 사업자 명의 통장을 만들고, 홈택스에 사업용 카드를 등록합니다. 결제 대행사 정산과 스토어 정산을 이 통장으로 받습니다.
  3. 구글 플레이 콘솔 가입(대표, 신원 확인 2~7일). 25달러 1회 결제. 개인 계정으로 가입하고 신분증 확인과 연락처 확인을 마칩니다. 가입 직후 앱을 하나 만들어 패키지 이름을 확보합니다(추천: kr.zodiac12.app 형식, 출시 뒤에는 바꿀 수 없음).
  4. 애플 개발자 프로그램 가입(대표, 1~2일). 연 99달러. 2단계 인증이 켜진 Apple ID가 필요하고, 아이폰의 Apple Developer 앱으로 가입하면 신원 확인이 빠릅니다.
  5. 도메인 구매(대표, 당일). 국내 등록업체에서 .com과 .kr 중 하나를 고릅니다(연 2~3만 원). 결정 후 도메인 이름을 알려 주시면 연결은 개발에서 합니다.
  6. Firebase 프로젝트 만들기(대표, 30분). 구글 계정으로 Firebase 콘솔에서 프로젝트를 만들고 Blaze 요금제(사용한 만큼)를 켭니다. 같은 화면에서 예산 알림을 월 3만 원으로 걸어 둡니다. 만든 뒤 개발용 서비스 계정 키 발급 방법은 개발에서 따로 안내합니다.
  7. 앱 이름 상표 확인(대표, 1시간). 특허정보검색서비스(KIPRIS)에서 「12지신 강림」과 비슷한 상표가 운세·앱 분야(9류·45류)에 있는지 봅니다. 겹치면 이번 주에 이름을 바꾸는 편이 스토어 등록 후보다 비용이 적습니다.
  8. 테스터 12명 섭외 시작(대표). 가족, 친구, 지인에게 안드로이드 폰과 구글 계정이 있는지 묻고 이메일 명단을 만듭니다. 이탈에 대비해 15명 이상을 권합니다. 테스트 기간 동안 하루 한 번 앱을 열어 달라고 미리 부탁합니다.
  9. 개발: 출시 구조 설계. Firebase 로그인, 구매 기록 저장 구조, Capacitor 포장 뼈대, 개인정보 처리방침·이용약관·환불 규정 초안 작성.

2주차 (11월 16일~22일): 결제 계약과 신고

  1. 심사용 웹사이트 확인(대표, 30분). 결제 대행사 심사에는 바닥글에 상호, 대표자, 사업자등록번호, 주소, 연락처, 통신판매업 신고번호(신고 전에는 「신고 진행 중」), 이용약관, 개인정보 처리방침, 환불 규정이 보이는 사이트 주소가 필요합니다. 개발에서 임시 주소에 올려 두면 내용이 실제 정보와 맞는지 확인해 주세요.
  2. 결제 대행사 가입 신청(대표, 심사 1~2주). 토스페이먼츠 또는 포트원(여러 대행사를 한 번에 연결) 중 하나로 신청합니다. 준비물: 사업자등록증, 대표자 신분증, 사업자 통장 사본, 사이트 주소, 상품 설명. 상품 설명은 「사주 풀이 디지털 콘텐츠(열람형), 990원~4,900원」으로 적습니다. 운세·점술 업종은 추가 서류를 요구받을 수 있으니, 신청할 때 상품이 오락용 디지털 읽을거리라는 점과 환불 규정을 함께 냅니다.
  3. 구매안전서비스 이용확인증 받기(대표). 결제 대행사 계약이 되면 관리 화면이나 고객센터에서 발급됩니다. 선결제 상품을 팔면 통신판매업 신고 때 이 서류가 필요합니다. 발급이 늦으면 구매안전서비스 비적용 대상 확인서로 신고할 수 있는지 담당 구청에 확인합니다.
  4. 통신판매업 신고(대표, 3~5일). 정부24 또는 시·군·구청에서 신고합니다. 준비물: 사업자등록증, 구매안전서비스 이용확인증, 신분증. 신고가 받아들여지면 등록면허세(지역에 따라 연 수만 원)를 내고 신고증을 받습니다. 신고번호를 알려 주시면 사이트와 앱 바닥글에 넣습니다.
  5. 스토어 판매 계약과 정산 정보(대표, 1~2일). App Store Connect의 「비즈니스」에서 유료 앱 계약(Paid Apps Agreement)에 동의하고 은행 계좌와 세금 양식(미국 세금 양식 W-8BEN, 한국 거주자 조약 혜택 표시)을 입력합니다. 구글 플레이 콘솔에서는 결제 프로필(판매자 계정)과 정산 계좌를 등록합니다.
  6. 스토어 수수료 감면 신청(대표, 10분). 애플 앱 스토어 소규모 사업자 프로그램(App Store Small Business Program)을 신청하면 수수료가 30%에서 15%로 내려갑니다. 구글은 연 매출 100만 달러까지 15%가 자동 적용됩니다.
  7. 약관·처리방침 최종 확인(대표, 1시간). 개발에서 드린 초안에서 회사 정보, 고객센터 이메일, 개인정보 보호책임자(대표 본인 가능) 이름을 채우고 내용을 읽어 확정합니다.
  8. 개발: 서버 기능 옮기기. 아티팩트 전용 기능을 Firebase로 바꿉니다(아래 「서버로 옮길 기능」 표). 로그인, 구매 기록 동기화, 웹 결제 승인 함수, 계정 삭제 기능을 만듭니다.

3주차 (11월 23일~29일): 상품 등록과 비공개 테스트 시작

  1. AI 상담용 API 키 등록(대표, 20분). Claude API 콘솔에서 결제 수단을 등록하고 키를 만든 뒤, 월 사용 한도를 정합니다(예: 월 5만 원). 키는 채팅에 붙여 넣지 말고, 개발에서 안내하는 Firebase 비밀값 등록 명령으로 직접 넣어 주세요.
  2. 인앱 상품 등록(대표, 1시간). 두 스토어에 같은 상품 ID로 4개를 만듭니다: premium_year(그해 상세판), life_report(평생 정통사주), compat_detail(궁합 상세), bundle_allinone(올인원). 복떡 꾸러미 3개(tteok_10, tteok_35, tteok_130)도 같은 방식으로 등록합니다. 모두 「소모품이 아닌 상품」과 「소모품」을 구분해야 하므로 개발에서 표를 드립니다. 애플의 원화 가격 단계에 990원이 없으면 가장 가까운 단계로 맞추고 웹 가격과 같게 할지 정합니다.
  3. 연령 등급 설문(대표, 20분). 두 스토어의 설문에 답합니다. AI 대화와 친구 우편함(사용자끼리 메시지)이 있으므로 「사용자 간 소통 있음」에 표시합니다. 예상 등급은 12세 이상입니다. 유료 뽑기를 판매하지 않는 설정(SELL_SUBSCRIPTION = false)을 출시판에서도 유지합니다.
  4. 개인정보 표시 양식(대표, 1시간). 구글의 데이터 보안 섹션과 애플의 개인정보 라벨에 답합니다. 개발에서 수집 항목표(이메일, 계정 번호, 구매 기록, 대화 내용, 기기 안에만 두는 생년월일)를 드리면 그대로 옮기면 됩니다.
  5. 11월 27일(금)까지 구글 비공개 테스트 시작(대표). 개발에서 만든 앱 묶음 파일(AAB)을 비공개 테스트 트랙에 올리고, 테스터 이메일 명단을 넣은 뒤 참여 링크를 보냅니다. 12명 이상이 「테스터 되기」를 눌렀는지 콘솔에서 확인합니다. 이날부터 14일을 셉니다.
  6. TestFlight 내부 테스트(대표, 30분). 개발에서 iOS 빌드를 올리면 본인 아이폰에 TestFlight로 설치해 첫 화면, 결제(샌드박스), 로그인, 계정 삭제를 직접 눌러 봅니다.
  7. 개발: Capacitor 앱 완성. 안드로이드·iOS 빌드, 인앱 결제 연결, 아침 알림, 첫 실행 화면, 앱 아이콘과 시작 화면.

4주차 (11월 30일~12월 6일): 테스트 운영과 스토어 문구

  1. 테스터 관리(대표, 매일 5분). 테스터에게 하루 한 번 앱을 열고 불편한 점을 한 줄 보내 달라고 알립니다. 받은 의견은 이 작업 창에 그대로 붙여 주시면 고칩니다. 구글은 정식 출시 신청 때 테스트에서 무엇을 배웠는지 묻습니다.
  2. 스토어 등록 문구 확정(대표, 1시간). 아래 「스토어 등록 문구 초안」을 읽고 고칠 곳을 알려 주세요.
  3. 스크린샷과 그래픽 확인(대표). 개발에서 아이폰 6.9인치, 아이패드(지원 시), 안드로이드 휴대전화 크기로 스크린샷 각 5~8장과 구글용 그래픽 이미지(1024×500)를 만들어 드립니다. 실제 화면과 같은지 봐 주세요.
  4. 고객센터 준비(대표, 30분). 문의용 이메일 주소를 하나 만들고(예: help@도메인), 환불 요청에 답할 문장을 개발에서 드린 초안으로 저장합니다.

화면에 넣을 표시와 고지

  • 재미 요소 안내: 운세와 사주 풀이는 전통 이론을 바탕으로 한 오락용 읽을거리이며, 의료·법률·투자 판단의 근거가 아니라는 문장을 결제 창, 약관, 스토어 설명에 둡니다.
  • 환불 규정: 디지털 콘텐츠는 열람을 시작하면 청약철회가 제한될 수 있으나, 그 사실을 결제 전에 알리고 맛보기를 제공해야 합니다. 결제 창에 「구매 후 풀이를 열기 전에는 7일 안에 환불, 연 뒤에는 환불이 어려움」을 표시하고, 지금의 맛보기(목차와 첫 문단)를 유지합니다.
  • 사업자 정보: 웹 바닥글과 앱 설정 화면에 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처를 표시합니다.
  • 확률 공개: 무료 뽑기의 확률 공개는 유지합니다. 유료 뽑기를 다시 판매하면 게임물로 분류될 수 있어 게임 등급 분류와 확률형 아이템 정보 공개 의무가 생기므로, 출시판에서는 판매하지 않습니다.
  • 위기 안내: 마음 날씨 천둥이 이어질 때 보이는 109 안내는 그대로 둡니다.
  • 계정 삭제: 앱 안 설정에서 계정 삭제가 바로 되도록 합니다. 애플 심사 필수 항목입니다.
