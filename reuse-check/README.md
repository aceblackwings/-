# 재사용·반복 콘텐츠 자가 점검기 (시제품 v0.1)

올리기 **전에** 내 영상이 유튜브 수익 창출 정책의 두 항목에 걸릴 위험이 있는지 스스로 점검합니다.

- **재사용 콘텐츠**: 남의 영상을 쓰되 시청자가 「의미 있는 차이」를 알아볼 수 있는가
- **진정성 없는(반복·대량 생산) 콘텐츠**: 내 지난 영상과 틀·인트로·대본이 지나치게 같은가

> 참고용 점검입니다. 유튜브의 실제 심사 결과를 보장하지 않습니다.
> 기준: [YouTube 채널 수익 창출 정책](https://support.google.com/youtube/answer/1311392)

## 브라우저 프로그램 「재사용 검수실」 (설치 없음, v0.2)
- 파일: `web/index.html` 하나. 크롬·엣지·사파리에서 열고 **내 영상 / 가져다 쓴 원본 / 내 지난 영상**을 끌어다 놓거나 골라 넣은 뒤 「분석 시작」.
- 영상은 기기 안에서만 분석합니다(서버로 보내지 않음). 앞 20분까지 분석.
- 결과: 재사용·반복 위험 점수, 영상 재생기 + V1(화면)/A1(소리) 트랙(누르면 그 시각으로 이동), 시간 붙은 고칠 점(누르면 이동), 세부 수치, 「결과를 글로 복사」.
- 미리 보기(비공개, 공유는 페이지의 Share 메뉴): https://claude.ai/artifact/RsBhyryaEWvvinzCrAtHuL
- 분석 방식은 아래 Python 판과 같음(같은 기준값). 브라우저 시험: `node web/test_web.mjs [webm 폴더]` (Playwright 크로미움은 H.264를 못 열어 시험 영상은 webm)

## 사용
```bash
python3 reuse_check.py 내영상.mp4 \
  --source 원본.mp4 [--source 원본2.mp4] \
  [--history 지난영상1.mp4 --history 지난영상2.mp4] \
  [--script 이번대본.txt --history-script 지난대본.vtt] \
  --out 결과폴더
```
결과: `결과폴더/report.html`(핸드폰에서도 보기 좋은 보고서), `결과폴더/result.json`(초 단위 타임라인 포함)

원본 영상·자막은 **내 PC에서** 받아 두세요. (클라우드 서버에서는 유튜브가 자막·영상 요청을 막습니다.)
```bash
yt-dlp -f "bv*[height<=480]+ba/b[height<=480]" -o 원본.mp4 "원본 영상 주소"
yt-dlp --skip-download --write-auto-subs --sub-langs ko -o 내대본 "내 영상 주소"
```

## 검사 방법
| 검사 | 방법 | 위험 신호 |
|---|---|---|
| 화면 겹침 | 1초에 2장 뽑아 지각 해시(pHash) 비교. 좌우 반전·약간 자르기도 찾음 | 원본이 화면 전체에 오래 나옴 |
| 화면 속 화면 | 9가지 크기 × 8px 간격 창으로 원본이 작게 들어간 곳을 찾음 | (변형으로 보아 가중치 낮음) |
| 소리 겹침 | 50ms마다 33대역 에너지 차이 비트 지문, 1초 창 비교 | 원본 소리 비율이 높음 |
| 내 목소리 | 원본이 아닌 새 소리 중 1초 안 음량 변동이 큰(말소리 같은) 구간 | 해설 35% 미만 |
| 원본 단독 구간 | 화면 원본 + 소리 원본/무음이 이어진 가장 긴 시간 | 10초 초과 |
| 반복 | 지난 영상과 같은 장면 비율, 대본 글자 3-gram 유사도 | 같은 인트로·같은 대본 틀 |

점수: **재사용 위험**(0~100, 35 주의 · 60 높음)과 **반복·대량 생산 위험**(0~100, 30 주의 · 60 높음)을 따로 냅니다.
기준값은 `reuse_check.py` 맨 위 상수와 `score()`에서 조정합니다. 실제 통과·거절 사례로 맞춰 나가야 합니다.

## 시험
```bash
python3 -m unittest test_reuse_check.py   # 인터넷 없이 ffmpeg 합성 영상으로 시험
```
시험용 실제 영상(Pixabay 영상 + 합성 음성) 결과(2026-11-25):

| 영상 | 만든 방법 | 재사용 위험 | 반복 위험 |
|---|---|---|---|
| 재사용본 | 원본을 좌우 반전·색 보정·5% 빠르게, 원본 소리 그대로 | **90 높음** | 0 |
| 해설 변형본 | 내 화면 인트로 + 원본 화면 속 화면 + 한국어 해설, 원본 단독 6초 | **14 낮음** | 22 (지난 영상과 같은 인트로 11초 지적) |
| 내 영상만 | 원본 사용 없음 | 5 이하 | 0 |

## 한계와 다음 단계
- 원본 파일이 있어야 화면·소리 겹침을 봅니다. 원본을 모르면 반복 점검만 됩니다.
- 말소리 판별은 음량 변동만 봅니다 → 다음: Whisper로 받아 적어 「분당 해설 글자 수」와 대본 유사도를 자동 계산.
- 화면 속 화면 찾기는 영상 길이에 비례해 느려집니다(50초 영상 약 10초) → 다음: 장면 전환 지점만 검사.
- 웹 화면(핸드폰 업로드) · 여러 원본 자동 찾기는 2~3단계에서.
